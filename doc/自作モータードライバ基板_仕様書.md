# maxon EC45 flat 制御用 自作モータードライバ基板 仕様書

**プロジェクト名:** maxon EC45 flat 70W モーター制御基板
**作成日:** 2026-02-01
**対象モーター:** maxon EC45 flat 70W (651614)

---

## 1. 概要

本基板はmaxon EC45 flat 70W ブラシレスモーター（型式651614）を制御するための専用モータードライバ基板です。

**用途:** 電動アシスト用高性能モーターコントローラ
**制御方式:** FOC（Field Oriented Control）による正弦波PWM駆動
**電源:** マキタ製18Vバッテリー（BL1820B）駆動
**特徴:**
- 3段階アシストレベル切替
- ターボモード搭載
- 6軸IMUセンサーによるモーション検出
- 高効率・低ノイズ駆動
- 回生回路による過電圧保護
- 多重温度監視による安全設計

### 主要コンポーネント

| カテゴリ | デバイス | 製造元 | 型番 |
|---------|---------|--------|------|

### 電流検出

| 項目 | 仕様 | 備考 |
|------|------|------|
| 検出方式 | シャント抵抗方式 | DRV8302内蔵アンプ使用 |
| シャント抵抗値 | 10 mΩ | ローサイド3相分 |
| アンプゲイン | 10 V/V | GAIN端子プルダウン設定 |
| 最大検出電流 | 約33A (理論値) | 計算式参照 |
| 検出レンジ（ADC入力） | 0 ～ 3.3V | VREF = 3.3V中心 |

**電流検出計算:**
```
シャント抵抗電圧降下: V_shunt = I × 10mΩ
アンプ出力電圧: V_out = VREF ± (V_shunt × Gain)
               V_out = 3.3V ± (I × 0.01Ω × 10)

最大検出電流 (片側振幅3.3V時):
I_max = 3.3V / (0.01Ω × 10) = 33A

実用検出範囲（±1.65V振幅時）:
I_range = ±16.5A
```

**注意:** モーター起動電流42Aはこの検出範囲を超えるため、過電流保護が重要です。

## 7. 保護機能

### ハードウェア保護（DRV8302内蔵）

- [x] 過電流保護 (OCP)
- [x] 過電圧保護 (OVP)
- [x] 低電圧保護 (UVLO)
- [x] 過熱保護 (OTP)
- [x] ショート保護

### ハードウェア保護（基板実装）

#### 1. 逆流防止ダイオード

- **目的:** モーターの逆起電力による電流の逆流を防止
- **実装位置:** バッテリー入力部
- **ダイオードタイプ:** ショットキーダイオード（実装品の型番は基板を確認）
- **定格:** 耐圧 ≧ 30V、電流 ≧ 10A
- **順方向電圧降下:** 約0.3～0.5V

**機能:**
- モーターが発電機として動作した際の逆電流をブロック
- バッテリーへの逆充電を防止

#### 2. 回生回路（ブレーキ抵抗回路）

- **目的:** 逆起電圧による入力部での過電圧を防止
- **構成:** 回生抵抗(20Ω×2並列=10Ω) + コンパレータ(UPC277G2) + MOSFET(TPH2R506PL)
- **動作:** 逆起電圧検出時、抵抗で回生電力を熱に変換
- **抵抗仕様:** 20Ω × 2個並列（合成10Ω）、各100W以上推奨
- **温度監視:** サーミスタ1個（AN3で監視）

**回生回路の動作:**
```
モーター減速時
    ↓
逆起電圧発生（モーターが発電機として動作）
    ↓
バス電圧上昇
    ↓
コンパレータ(UPC277G2)が過電圧検出
    ↓
回生MOSFET ON
    ↓
回生抵抗(10Ω)で電力を熱に変換
    ↓
バス電圧を39V以下に維持
```

**回生回路制御:**
- トリガ電圧: 39V（分圧比 15k/(180k+15k)、基準電圧3.0V）
- 制御方式: ハードウェア自動（コンパレータ直結、MCU不要）
- 温度保護: AN3による温度監視、過熱時は出力制限
- 詳細は [回生回路設計書.md](回生回路設計書.md) を参照

#### 3. 温度保護（サーミスタ）

| 位置 | 監視対象 | ADC入力 | 保護動作 |
|------|---------|---------|---------|
| インバータ部 | MOSFET/パワー回路 | AN2 | 過熱時：出力ディレーティング/停止 |
| 回生回路部 | 回生抵抗 | AN3 | 過熱時：回生動作制限/警告 |

**温度保護閾値（推奨）:**
- 警告温度: 70～80°C（出力制限開始）
- 停止温度: 90～100°C（緊急停止）
- 復帰温度: 60°C以下

### ソフトウェア保護

- [x] 電流制限: 実装必須（起動電流抑制、過電流保護）
- [x] 速度制限: 実装推奨（最大回転数制限）
- [x] 温度監視: 実装済み（AN2, AN3）
- [x] バッテリー電圧監視: 実装済み（AN1）

## 8. 制御方式

### モーター制御アルゴリズム

- **制御方式:** 正弦波PWM / FOC制御（Field Oriented Control）
  - [x] 正弦波PWM駆動（FOC: Field Oriented Control）
  - 高性能、低ノイズ、高効率
  - ホールセンサによる位置検出
  - ベクトル制御による高度なトルク制御

### FOC制御の特徴

**メリット:**
- 高効率運転（矩形波駆動比で5～10%向上）
- 低振動・低ノイズ
- 滑らかなトルク出力
- 広範囲な速度制御
- 精密な電流制御

**実装要件:**
- Park変換・Clarke変換の演算
- 電流フィードバック（3相）
- PWM高速更新（16kHz推奨）
- MCU高速演算能力（RA6T2のFPU活用）

### フィードバック制御

- **速度制御:** PID制御
- **電流制御:** PI制御（dq軸電流制御）
- **位置制御:** ホールセンサベース
- **トルク制御:** 電流ベクトル制御

### 動作モード

本システムは電動アシスト用途として以下のモードを実装：

#### 1. アシストレベル（3段階）
- **Level L（低）:** 軽アシスト
- **Level M（中）:** 標準アシスト
- **Level H（高）:** 強アシスト

#### 2. ターボモード
- 最大出力での一時的なパワーブースト
- 電流制限内での最大トルク出力

#### 3. 保護モード
- 過電流検出時の出力制限
- 過熱保護
- バッテリー低電圧保護

## 10. 熱設計

### 放熱設計

| デバイス | 発熱（推定） | 放熱対策 |
|---------|------------|---------|
| MOSFET (TPH2R506PL) | 約3～5W（連続時） | 基板銅箔放熱、サーマルビア |
| DRV8302 | 約1～2W | 基板銅箔放熱、サーマルパッド |
| MCU (RA6T2) | 約0.5W | 基板銅箔放熱 |
| LDO (ISL9001) | 約0.3～0.5W | 基板銅箔放熱 |

**放熱板:**
- 使用有無: なし（ヒートシンクレス設計）
- 基板放熱: 4層基板の内層銅箔を放熱層として活用
- サーマルビア: パワー部品下に多数配置
- 冷却ファン: なし

**熱設計の考慮事項:**
⚠ **重要:** ヒートシンクなしの設計のため、以下の点に注意が必要
1. MOSFETのオン抵抗による発熱（Rds(on) = 2.5mΩ）
2. 連続運転時の温度上昇
3. 周囲温度の影響
4. 基板銅箔面積の最大化
5. サーマルビアによる熱伝導

**発熱計算（概算、連続3.29A時）:**
```
MOSFET発熱（6個合計）:
P = I² × Rds(on) × デューティ比
P ≈ (3.29A)² × 2.5mΩ × 2個（常時ON） × 3相
P ≈ 0.16W （理論最小値）

実際は導通損失 + スイッチング損失で 3～5W程度と推定
```

**推奨モニタリング:**
- MOSFET温度センサー（サーミスタ）の実装推奨
- 過熱保護ロジックの実装
- 温度に応じた出力ディレーティング

## 16. 既知の問題・注意事項

1. **電圧不整合:** モーター定格24Vに対しバッテリー18V。性能は約75%に低下（トルク定数は変わらず、最大回転数が低下）
2. **電流検出範囲超過:** 起動電流42Aがシャント検出上限(±8.25A設定値、理論33A)を超える可能性。ソフトウェア電流制限で起動電流を抑制
3. **コネクタ変換:** モーター側(Molex 39-28-1083)と基板側(JST B4PS-VH + S12B-PUDSS)でコネクタが異なり、変換ケーブルが必要
4. **ヒートシンクなし設計:** 連続大電流時の温度上昇に注意。サーミスタ監視と出力ディレーティングが必須
5. **FOC制御のKi不安定:** 電流PI制御のKi>0で発振・ワインドアップが発生。現在P制御のみ(Ki=0)で動作
6. **速度制限が保守的:** N_base=1559rpm（定格の33%）、Iq制限=0.194PU（定格の19%）。調整が必要
