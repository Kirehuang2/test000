### 特に注意が必要な変更

**Ki_id/Ki_iq = 835:**
- 積分器増分 = 835 × 0.0001 × error = 0.0835/sample (最大誤差1.0PU時)

- モーターパラメータ (L/R = 519μs) から正しく算出されているが、
  実機ではノイズや遅延により発振リスクあり
- **Back-calculation AW** を実装済みで過大出力を抑制

### Phase 1: トルク制御 低電流テスト (最重要)

**目的:** 新PIゲイン・デカップリングの安定性確認

1. **モーター接続、無負荷、軸は手で触れる状態**
2. デバッガで以下を設定:
   ```
   control_mode = 1  (トルク制御)
   torque_ref_iq = 0.03  (0.03 PU = 0.50A, 定格の15%)
   torque_ref_iq_max = 0.06  (0.06 PU = 1.0A, 安全リミット)

3. `Enable = 1` → **即座にIdFb, IqFbを監視**

   - [ ] 異音・振動なし
   - [ ] 回転が滑らか
4. 10秒間運転 → `Enable = 0`
5. **異常時:** `Enable = 0` → バッテリー切断

**判定基準:**
- IdFb < 0.03 → デカップリング正常
- IdFb > 0.05 → hall_angle_offset再キャリブレーション必要
- 振動・異音 → Ki_id/Ki_iq を半分に下げて再試行 (50→25)

**Phase 1成功後のKi段階引き上げ:**
```
SET Ki_id 100 / SET Ki_iq 100 → 10秒安定確認

## 4. 緊急停止手順

### 異常検出時の即時対応

**以下の場合は直ちに停止:**
- 異音(キーキー音、ガタガタ) → PI発振の可能性
- 異臭(焦げ臭い) → 過電流
- モーターの急激な加速 → 速度PI発散
- IqFb > 0.25PU (4.1A) が持続 → 制御異常
- IdFb > 0.10PU が持続 → 角度オフセット不正

**停止方法 (優先順):**
1. デバッガで `Enable = 0` に設定
2. デバッガ一時停止 (Pause)
3. バッテリーコネクタ切断 (物理遮断)

### 発振時の対処

Ki値が高いため、実機で発振する場合:
1. `Enable = 0`
2. デバッガで Ki_id, Ki_iq を 418.0 に変更 (帯域を250Hzに低下)
3. 再度 `Enable = 1` で確認
4. まだ発振する場合: Ki_id, Ki_iq = 100.0 (帯域~60Hz)
