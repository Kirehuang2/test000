## 1. 概要

### 1.1 目的

電源遮断時（バッテリー抜去・緊急停止スイッチ作動・異常検出ラッチ等）に、
吊り下げ荷物の急落下を防ぐ受動的フェールセーフブレーキを実装する。

### 1.2 動作原理

モータ-ドライバ間にNC（ノーマリクローズ）接点リレーを挿入する。

```
電源ON  : コイル励磁 → NO閉 → モータ⇔ドライバ（通常運転）
電源OFF : コイル消磁 → NC閉 → U/V/W 3相短絡（発電制動）
```

モータが発電機として動作し、back-EMFが短絡電流を駆動、ローレンツ力により制動トルクが発生する。
制動トルクは回転速度に比例するため、静止保持はできないが急落下を抑制する。

### 1.3 設計目標

| 項目 | 目標値 |
|------|-------|
| 吊り荷重 | 20kg（連続運転設計点）、最大30kg |
| 電源遮断後の定常落下速度 | ≤ 100 mm/s |
| 制動中のリレー接点電流 | ≤ 8A（G5LE-1の直流接点定格） |
| コスト | 機械式保持ブレーキの1/10以下 |
| 体積 | 基板上に実装可能（PCBリレー） |

### 1.4 採用方針

1. **3相短絡方式**（機械式保持ブレーキは採用しない）
   - 理由：荷重20kg、ドラムφ18mm、減速比15.04の組合せで落下速度が十分遅い
   - ゆっくり落下でOK（完全停止は不要）の要件を満たす
2. **制限抵抗を短絡経路に直列挿入**
   - 理由：電源断の瞬間の過渡電流を接点定格内に抑える

## 4. 制動理論

### 4.1 3相短絡時の制動トルク

#### 4.1.1 諸定義

相-相back-EMFピーク値：
```
V_ll_peak = Ke × ω_m   [V]
```

相（line-to-neutral）back-EMFピーク値（Y結線）：
```
V_ph_peak = V_ll_peak / √3
```

1相の電流経路抵抗（各相に制限抵抗を直列挿入）：
```
R_ph + R_limit
```

#### 4.1.2 3相合計消費電力

1相の時間平均電力：
```
P_1相 = V_ph_rms² / (R_ph + R_limit)
      = V_ph_peak² / [2 × (R_ph + R_limit)]     ← 係数2: RMS²=peak²/2
```

3相合計：
```
P_total = 3 × V_ph_peak² / [2 × (R_ph + R_limit)]
```

V_ph_peak² = V_ll_peak² / 3 を代入（係数3と1/3が相殺）：
```
P_total = V_ll_peak² / [2 × (R_ph + R_limit)]
```

#### 4.1.3 合計抵抗 R_total の定義

R_ll = 2 × R_ph（Y結線、端子間で2相直列）より：
```
2 × (R_ph + R_limit) = 2×R_ph + 2×R_limit = R_ll + 2×R_limit
                    ≡ R_total   [Ω]
```

∴
```
P_total = V_ll_peak² / R_total = (Ke × ω_m)² / R_total
```

#### 4.1.4 制動トルク

機械的出力 = 電気的消費電力：
```
T_brake × ω_m = P_total = Ke² × ω_m² / R_total
```

∴
```
T_brake = Kt² / R_total × ω_m   [Nm]   ... (式1)
```
（Ke = Kt の SI系換算を使用）

**検算：** 最大速度 ω_m = 586 rad/s、R_limit=0 のとき
T_brake = 0.0404² / 0.573 × 586 = 1.69 Nm ≒ 停動トルク ✓

### 4.2 荷重トルクのモータ軸換算

ドラム半径 r、減速比 N、荷重 m [kg] のとき：
```
T_load = m × g × r / N   [Nm]   ... (式2)
```

| 荷重 | T_load（モータ軸） |
|------|-------------------|
| 20 kg | 0.1174 Nm |
| 30 kg | 0.1762 Nm |

### 4.3 速度変換

荷物の落下速度 v [m/s] とモータ角速度 ω_m [rad/s] の関係：
```
ω_m = v × N / r   [rad/s]   ... (式3)
```

### 4.4 定常落下速度

式1＝式2（制動トルク＝荷重トルク）より：
```
Kt² / R_total × (v × N / r) = m × g × r / N
```

∴
```
v_eq = m × g × r² × R_total / (Kt² × N²)   [m/s]   ... (式4)
```

## 5. 制限抵抗の設計

### 5.1 制限抵抗なしの場合（比較）

R_limit = 0、R_total = 0.573Ω

| 項目 | 値 |
|------|-----|
| 定常落下速度（20kg） | **24.6 mm/s** |
| 定常落下速度（30kg） | 36.9 mm/s |
| 運転速度60mm/sでの接点電流 | 7.1 A（限界ぎりぎり）|
| 運転速度100mm/sでの接点電流 | **11.8 A（定格超過！）** |

**問題点：** 運転中に電源断が発生した瞬間、モータの残回転によりリレー接点に過大な短絡電流が流れる。
バランサの通常運転速度が100mm/sに達する場合、接点8A定格を超える。

### 5.2 制限抵抗挿入時の電流と落下速度

回転数に対する短絡電流：
```
I_sc = V_emf_ll / R_total = Ke × ω_m / R_total   [A]   ... (式5)
```

| R_limit | R_total | v_eq (20kg) | v_eq (30kg) | I_sc @60mm/s | I_sc @100mm/s |
|---------|---------|-------------|-------------|--------------|---------------|
| 0 Ω | 0.573 | 24.6 mm/s | 36.9 mm/s | 7.07 A | 11.78 A |
| 0.3 Ω | 1.173 | 50.4 mm/s | 75.6 mm/s | 3.46 A | 5.76 A |
| **0.5 Ω** | **1.573** | **67.6 mm/s** | **101.4 mm/s** | **2.58 A** | **4.30 A** |

### 5.3 抵抗値選定

**R_limit = 0.5Ω を採用**

選定理由：

1. **接点電流マージン**：通常運転速度60mm/sで I_sc = 2.58A であり、
   G5Q-14 の直流接点定格5Aに対して約48%使用（52%マージン）
   運転速度100mm/sでも 4.30A で定格内
2. **落下速度**：20kgで67.6mm/s（≈4 m/min）は目標100mm/s以内で十分安全
3. **標準品入手性**：0.47Ω（E24系列）または0.5Ω（セメント抵抗の定番値）で入手容易

**運用上の制約：** 通常運転速度は **100mm/s 以下** とすること。
バランサの実用速度（30〜60mm/s）では十分なマージンあり。
100mm/s超での電源断は接点5A DC定格を超過するが、短時間過渡のためG5Q-14は耐えうる。

## 6. 制限抵抗の電力定格

### 6.1 定常落下時の発熱

荷物が定常落下しているとき、位置エネルギーが全て抵抗で消費される。

```
P_total = m × g × v_eq   [W]   ... (式6)
```

このうち、モータ巻線とR_limitで配分される：
```
P_motor    = P_total × R_ll / R_total
P_limiters = P_total × 2×R_limit / R_total
P_per_R    = P_limiters / 3   (3個に配分、対称運転を仮定)
```

| 荷重 | v_eq | P_total | P_motor | P_limiters | **P_per_R** |
|------|------|---------|---------|------------|-------------|
| 20kg | 67.6 mm/s | 13.3 W | 4.84 W | 8.43 W | **2.81 W** |
| 30kg | 101.4 mm/s | 29.8 W | 10.9 W | 18.95 W | **6.32 W** |

### 6.2 抵抗定格選定

- 20kg運転（通常）：2.81 W/個 → **5W定格で1.8倍マージン**
- 30kg運転（最大）：6.32 W/個 → **5W定格では不足**、**10W定格が必要**

**選定：0.5Ω 10W セメント抵抗（5W相当の2倍マージン）× 3個**

### 6.3 継続時間の考察

フェールセーフブレーキは緊急停止用途であり、定常連続動作ではない。
典型的シナリオ：

- バッテリー抜去 → 荷物がストロークエンドまで落下 → 停止
- ストローク1m、落下速度100mm/sとすれば、約10秒で完了

10W定格抵抗は短時間（〜30秒）なら20W程度まで耐えるため、
30kg運転中の緊急停止でも問題なし。

## 7. モータ巻線の熱設計検証

### 7.1 制動中の巻線発熱

制限抵抗ありで20kg定常落下時：P_motor = 4.84 W

巻線温度上昇（定常）：
```
ΔT = P_motor × R_th = 4.84 × 9.19 = 44.5 °C
```

周囲25°Cから → 巻線温度 69.5°C（最大許容125°C）→ **余裕あり** ✓

30kg定常落下時：P_motor = 10.9 W
```
ΔT = 10.9 × 9.19 = 100.2 °C
```
巻線温度 125.2°C（最大許容125°C）→ **ギリギリ**

### 7.2 過渡解析

熱時定数 τ_th = 43.1s。緊急停止は通常10秒以内に完了するため、
定常到達前に停止する。過渡温度：
```
ΔT(t) = ΔT_steady × (1 - exp(-t/τ_th))
```

30kg、t=10s時： ΔT = 100.2 × (1 - e^-10/43.1) = 100.2 × 0.207 = 20.8°C
→ 巻線温度 45.8°C → **完全に安全**

**結論：** 緊急停止シナリオでは熱的に全く問題なし。

## 8. リレー選定

### 8.1 選定機種

**Omron G5Q-14 DC5（SPDT 1 Form C、10A AC / 5A DC、5VDCコイル）× 3個**

[Omron G5Q datasheet](https://omronfs.omron.com/en_US/ecb/products/pdf/en-g5q.pdf) 参照

基板上の既存5V電源（DRV8302内蔵バックコンバータ、容量1.5A）から駆動。

### 8.2 リレー選定経緯

| 候補 | 問題 |
|------|------|
| G5LE-1 DC18 | 2026-03 生産終了 ✗ |
| G5Q-14 DC18 | 公式G5Qデータシートのコイル電圧ラインナップは 5V/9V/12V/24V のみ、18V品は標準外 ✗ |
| G2R-1-E DC18 | 流通在庫はあるが、公式G2Rデータシート本体の標準ラインナップにDC18Vの掲載なし ✗ |
| **G5Q-14 DC5** | **標準ラインナップ品、継続供給確実** ✓ |

18Vコイルが標準ラインナップにある適切なOmronリレーが存在しないため、
**電源電圧に制約されないDC5Vコイル品を採用**し、基板上の既存5V電源から駆動する方式とした。

### 8.3 仕様適合性

| 項目 | 要求 | G5Q-14 DC5 | 判定 |

| 接点電流定格（DC） | ≥5A DC | 5A @30VDC | ○（要速度考慮） |
| 接点電流定格（AC） | 参考値 | 10A @250VAC | ◎ |
| 接点電圧定格 | ≥30VDC（バス電圧20V） | 30VDC | ◎ |

### 8.4 5V電源からのコイル駆動

#### 8.4.1 コイル仕様
- コイル定格電圧 V_rated = 5 VDC
- コイル消費電力 P_coil = 400 mW
- コイル抵抗 R_coil = V²/P = 5² / 0.4 = **62.5Ω**
- 定格時コイル電流 I_coil = 5 / 62.5 = **80 mA/個**

#### 8.4.2 5V電源負荷試算

| 負荷 | 電流 |
|------|-----|
| フェールセーフブレーキリレー（3個） | **240 mA** |
| ISL9001 LDO入力（→3.3V MCU給電） | 約100〜200 mA |
| ホールセンサ電源（maxon 651614） | 約5 mA |
| その他（LED等） | 約10 mA |
| **合計** | **約350〜450 mA** |

DRV8302 内蔵バックコンバータの容量 **1.5A** に対し、使用率30%以下で十分な余裕。

#### 8.4.3 電源断時の動作

- バッテリー電源遮断 → DRV8302バック停止 → 5V消失
- 5V消失 → コイル消磁 → リレーNC側へ切替 → 3相短絡制動
- 所要時間：DRV8302停止（数ms）+ リレー動作（〜15ms）≈ 20ms 以内

### 8.5 型番の注意

| 型番 | 接点 | 採用可否 |
|------|------|---------|
| **G5Q-14 DC5** | SPDT 1 Form C（NO+NC） | ✓ **採用** |
| G5Q-14-EU DC5 | SPDT、EU版（絶縁強化）| ○ 上位互換 |
| G5Q-1A DC5 | **SPST-NO（NCなし）** | ✗ 使用不可 |
| G5Q-1A4 DC5 | **SPST-NO（NCなし）密閉型** | ✗ 使用不可 |

**"1A"や"1A4"はNOのみ。必ず"14"（= 1 Form C）を指定すること。**

- DigiKey、Mouser、Newark、RSコンポーネンツ、共立電子 他で正規流通

## 9. 回路構成

### 9.1 主回路（パワー側）

```
              [U相]                    [U相]
  Driver_U ──[NO]─[COM]── Motor_U     R_limit=0.5Ω/10W
              [NC]─────────────────┐
                                   │
              [V相]                 │
  Driver_V ──[NO]─[COM]── Motor_V  │  (短絡バス)
              [NC]─────────[R_L]───┼──┐
                                   │  │
              [W相]                 │  │
  Driver_W ──[NO]─[COM]── Motor_W  │  │
              [NC]─────────[R_L]───┘  │
                                      │
                           [R_L]──────┘
                          ↑ U相のR_L
```

各相のNC接点 ─ 制限抵抗（0.5Ω/10W） ─ 共通短絡バス。

動作：
- コイル励磁時：COM⇔NO（Driver⇔Motor 接続、NC側は開放）
- コイル消磁時：COM⇔NC（Motor 3相がR_Lを介して短絡）

### 9.2 コイル駆動回路

```
+5V (DRV8302内蔵バック出力) ──┬─────────┬─────────┐
                              │         │         │
                            [Coil1]   [Coil2]   [Coil3]
                            62.5Ω    62.5Ω    62.5Ω
                            80mA     80mA     80mA
                              │         │         │
                              ├─[D1]◁──┤         │   ← フライホイールダイオード
                              │         ├─[D2]◁──┤     (1N4148 or 1N4007)
                              │         │         ├─[D3]◁──┐
                              │         │         │         │
                              └─────────┴─────────┴─────────┴── MOSFET ドレイン
                                                                  │
                                                                  G ←─[100Ω]─ MCU GPIO (BRAKE_EN#)
                                                                  │     │
                                                                  │    [10kΩ] → GND (プルダウン)
                                                                  │
                                                                  S → GND
```

**設計ポイント：**
- MCU から `BRAKE_EN#` 信号（Active High = 運転可、Low = 制動）でMOSFETを駆動
  - 通常運転中：MOSFET ON → コイル励磁（5V → GND）→ NO側導通 → 運転可能
  - 異常検出・起動前：MOSFET OFF → コイル消磁 → NC側導通 → 3相短絡制動
- フライホイールダイオード（1N4148 × 3）：コイル逆起電力からMOSFET保護
  - 5V系なので小信号ダイオードで十分（ピーク電流 < 100mA）
- MOSFETは論理レベル N-ch、例：**AO3400A**（30V/5.8A/SOT-23、Vgs(th)=1.3V）
  - 3.3V GPIO直接駆動可能
- ゲート直列抵抗 100Ω：スイッチングノイズ抑制
- **ゲートプルダウン 10kΩ 必須**：MCU起動前・リセット時の不定状態で安全側固定

### 9.3 フェールセーフ性の確保

以下のいずれかが発生すると自動的に制動状態に遷移：

1. **バッテリー抜去** → DRV8302バック停止 → 5V消失 → コイル消磁 → NC閉
2. **5V電源異常**（バック故障、過電流保護動作）→ 5V消失 → NC閉
3. **MCUリセット/暴走** → GPIO Hi-Z → プルダウンでMOSFET OFF → NC閉
4. **緊急停止スイッチ作動** → バッテリーライン遮断 → 5V消失 → NC閉
5. **ソフトウェア異常検出**（過電流ラッチ等）→ BRAKE_EN# = L → MOSFET OFF → NC閉

**重要：5V電源（DRV8302バック）が本方式のシングルポイントフェイルではない。**
- DRV8302 バック停止時 → 5V落ち → 即時制動（安全側）
- DRV8302 ゲート駆動異常時 → MCU検出 → BRAKE_EN# Low → 制動

**プルダウン抵抗 10kΩ をMOSFETゲートに追加必須**。

## 15. 別案：リレー接触抵抗が制御に影響しない構成（パターンB）

### 15.1 背景

§9.1 の現設計（以後 **パターンA** と呼ぶ）は、SPDTリレー接点をドライバ⇔モータ間の主回路に挿入する。
このため、通常運転中に接点抵抗 R_contact がモータ相抵抗と直列に入り、以下の制御面の副作用を生じる。

| 項目 | パターンA での影響 |
|------|-------------------|
| 実効相抵抗 | R_ph = 0.287Ω → **0.387Ω（+35%）**（G5Q-14 初期接点抵抗 100mΩ max 換算） |
| 銅損 / 接点自己発熱 | 定格3.29A時 **1.08W/個 × 3 = 3.24W** がリレー内部で発生 |
| ピーク電流時の接点負担 | 10A瞬時で **10W/個** — 接点寿命・溶着リスク増 |
| 相間非対称（80〜150mΩ の個体差・経年差） | **電流不平衡 → 6次高調波トルクリップル** |
| 経年劣化 | 開閉回数・アーク粗面化で R_contact 上昇 → **制御特性ドリフト**（接点300mΩ相当で相抵抗実効値2倍） |
| 電圧余裕 | 接点での電圧降下で高速域の電圧飽和が早まる |

FOC の電流ループ自体は電流FB で閉じるため電流値は正しく出るが、モデルベース項（フィードフォワード、
デッドタイム補償、トルク定数換算）の精度低下と、相間非対称によるトルクリップルは制御的に無視できない。

本セクションでは、制御路に接点抵抗を介在させない **パターンB** を別案として記載する。

### 15.2 基本アイデア

- ドライバ⇔モータ間は **直結**（リレーを介さない）
- リレーは **短絡バスへの分岐接点** として配置
- 通常運転中：リレー接点は主回路に介在しない → 接点抵抗ゼロ影響
- 電源OFF / 制動時：リレー NC が閉じてモータ端子が制限抵抗経由で3相短絡

### 15.3 回路構成

```
Driver_U ────────────────── Motor_U ──┬── [COM リレー1]
                                      │        │
                                      │     [NC]──[R_L 0.5Ω/10W]──┐
                                      │     [NO]（未接続）          │
                                      │                            │
Driver_V ────────────────── Motor_V ──┬── [COM リレー2]              │
                                      │        │                    │
                                      │     [NC]──[R_L 0.5Ω/10W]──┼── 短絡バス
                                      │     [NO]（未接続）          │     (3本を1点結線)
                                      │                            │
Driver_W ────────────────── Motor_W ──┬── [COM リレー3]              │
                                      │        │                    │
                                      │     [NC]──[R_L 0.5Ω/10W]──┘
                                      │     [NO]（未接続）
```

- ドライバ⇔モータ間は銅パターン直結（リレー接点なし）
- リレー は G5Q-14 DC5（SPDT）のまま流用可。NO 端子を **未接続**として使用することで SPST-NC 相当として動作
- 標準ラインナップ維持・BOM共通化の観点で SPDT流用とする（専用SPST-NC品の入手性より有利）

### 15.4 端子接続表（パターンB）

| リレー | COM 接続先 | NO 接続先 | NC 接続先 |
|---|---|---|---|
| リレー1 | Motor U端子（Driver U 出力と同ノード） | **未接続（オープン）** | R1(0.5Ω) → 短絡バス |
| リレー2 | Motor V端子（Driver V 出力と同ノード） | **未接続（オープン）** | R2(0.5Ω) → 短絡バス |
| リレー3 | Motor W端子（Driver W 出力と同ノード） | **未接続（オープン）** | R3(0.5Ω) → 短絡バス |

### 15.5 動作状態

| 状態 | コイル | 接点 | モータ回路 |
|---|---|---|---|
| 通常運転 | 励磁 | COM-NO 閉（NO開放のため実質切断）/ COM-NC 開 | Driver⇔Motor 直結、短絡バス切り離し |
| 電源断 / 異常 | 消磁 | COM-NC 閉 | モータ3端子が R_L × 3 を介して短絡 → 発電制動 |

短絡ループの抵抗は パターンA と同一（R_total = R_ll + 2×R_limit = 1.573Ω）。§4〜§7 の制動性能計算はそのまま適用可能。

### 15.6 トレードオフ（パターンA vs パターンB）

| 評価項目 | パターンA（現設計） | パターンB（側枝配置） |
|---|---|---|
| 制御路の接点抵抗 | **+100mΩ/相（+35%）** | **0mΩ（無影響）** ◎ |
| 相間非対称・経年ドリフト | 制御に直接影響 | 短絡路のみに影響（R_limit に埋もれる） |
| ドライバ切り離し（フェイルセーフ性） | **あり**（ドライバ暴走時もモータ確定） ◎ | なし（ドライバがモータに常時接続） |
| MCU暴走 / ソフト異常時の対応 | リレーNC単独で完結 | **別経路で EN_GATE OFF が必須**（§15.7） |
| 回路複雑度 | 主回路に3接点介在 | 主回路直結、分岐に3接点 |
| 使用部品 | G5Q-14 DC5（SPDT 1c）× 3 | G5Q-14 DC5（SPDT 1c、NO 開放）× 3 — BOM同一 |
| ドライバMOSFETボディダイオード経由の回生 | 発生しない（切断済） | 制動時に一部電流が経路化しうる（下記） |

**ボディダイオード経路の定量評価：**
DRV8302 の6個のMOSFETが全OFFの状態で、モータ相電圧ピーク V_ph_peak がバス電圧 V_bus を上回ると、
ハイサイドボディダイオードを通してバスコンデンサを充電しうる。
しかし R_limit 経由の短絡路抵抗 1.573Ω に対し、ダイオード順方向降下（〜0.7V）＋バスコンデンサへの充電経路は、
速度が十分下がると成立しなくなる（V_ph < V_bus + 2×Vf）。
電源断直後の高速域のみ一部電流がバス側に流れるが、短絡路が主経路として支配する。
→ 実用上の制動性能低下は数%以内にとどまる見込み（要実測）。

### 15.7 多重防護：STO（Safe Torque Off）併用

パターンBで **MCU暴走・ソフト異常検出** 時に主電源が生きたままブレーキをかけるには、
リレー短絡だけではドライバ出力が潰される可能性があるため、**一次手段として DRV8302 の `EN_GATE` を Low 駆動**してゲートを強制OFFする。

| トリガー | 一次手段 | 二次手段 | 備考 |
|---|---|---|---|
| 1. バッテリー抜去 | （バス自然消失で全MOSFET OFF） | リレーNC短絡 | パターンB動作 |
| 2. 5V電源異常 | EN_GATE Low（5V喪失で自然にLow） | リレーNC短絡 | |
| 3. MCUリセット | **EN_GATE Low（プルダウン固定）** | リレーNC短絡（BRAKE_EN# Lowで同時作動） | STO必須 |
| 4. E-stop（バッテリーライン遮断） | バス消失 | リレーNC短絡 | |
| 5. ソフト異常検出 | **EN_GATE Low（MCUが能動的にLow）** | BRAKE_EN# Low でリレーも作動 | STO + 短絡の二重作動 |

**実装要件（追加）：**
- DRV8302 `EN_GATE` 端子に **10kΩ プルダウン抵抗**を追加 → MCUリセット/Hi-Z時に自動OFF
- MCU 起動シーケンスで `EN_GATE` を Active High に遷移させる前に自己診断を実施
- ソフト異常検出時は `EN_GATE = Low` と `BRAKE_EN# = Low` を同時発行

### 15.10 推奨

本1軸サーボバランサ（pj:26-001）では、**パターンB + STO併用** を推奨する。

理由：
1. 接点抵抗100mΩが相抵抗0.287Ωに加算される影響は制御上有意（+35%）、経年ドリフトも予測困難
2. 相間非対称によるトルクリップルはバランサのゼロ点保持性能を劣化させる
3. DRV8302 の `EN_GATE` は元々実装可能で、追加コスト僅少（10kΩ × 1本）
4. ドライバ切り離しの機能は STO（ゲート強制OFF）で代替可能

最終採用判断は、実機での **パターンA の接点抵抗実測値・トルクリップル実測** を踏まえて §11 の動作検証後に確定する。
