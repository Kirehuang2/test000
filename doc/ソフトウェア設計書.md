## 4. 初期化シーケンス

```
hal_entry()
    │
    ├─ 1. RM_MOTOR_SENSE_HALL_Open()     // ホールセンサモジュール初期化
    │
    ├─ 2. FOCCurrentControl_initialize()  // FOC電流制御初期化
    │     SpeedControl_initialize()       // 速度制御初期化
    │
    ├─ 3. R_ADC_B_Open() / ScanCfg()     // ADC初期化
    │
    ├─ 4. R_GPT_THREE_PHASE_Open/Start() // 3相PWMタイマー起動
    │
    ├─ 5. EN_GATE_RESET → Low (1秒)      // DRV8302リセット
    │     EN_GATE_RESET → High           // DRV8302有効化
    │     待機 10ms                       // 安定化待ち
    │
    ├─ 6. R_ADC_B_ScanGroupStart()       // ADCスキャン開始
    │     (Group 0: 電流, Group 1: 監視)
    │
    ├─ 7. R_GPT_OutputEnable() × 3       // PWM出力有効化（W/V/U相）
    │
    ├─ 8. R_GPT_Open/Enable/Start()      // 1msタイマー起動
    │     (timer4: 1kHz周期)
    │
    └─ 9. while(1) { }                   // メインループ（空）
```

## 5. 割り込みコールバック詳細

### 5.1 ADCコールバック: rm_motor_driver_cyclic() [10kHz]

```
rm_motor_driver_cyclic(ADC_GROUP_MASK_0)
    │
    ├─ 1. DRV8302フォルト検出
    │     nFAULT pin → drv8302_fault
    │     fault → drv8302_fault_latched → Enable=0, PWM=50%
    │
    ├─ 2. ADC読取
    │     Group 0 FIFO: W相電流, V相電流, 温度×2, バッテリー電圧
    │     physical_channelで動的マッチング（7ch統合）
    │
    ├─ 3. 監視チャネル変換
    │     battery_voltage = ADC × 3.3V/4095 × 13
    │     temp_inverter = NTC B-parameter変換
    │     temp_regen = NTC B-parameter変換
    │
    ├─ 4. 速度指令ランプ生成
    │     0 → 0.03 PU (約6秒)
    │
    ├─ 5. Enable遅延 (100ms後にEnable=1)
    │
    ├─ 6. ホールセンサ角度/速度取得
    │     f_get_angle: 電気角（FSP補間済み、u2_maximum_period=2000）
    │     f_get_speed: 電気角速度（f_pwm_carrier_freq=10.0）
    │
    ├─ 7. 角度微分速度推定（10ms窓スライディング）
    │     f_get_angle アンラップ → リングバッファ(100点)
    │     speed = (angle_now - angle_100ago) / 10ms
    │     IIRフィルタ (speed_filter_alpha=0.10)
    │     → SpeedFb_Hall_PU, SpeedFb_RPM
    │
    ├─ 8. FOCCurrentControl_step()
    │     入力: Enable, IdqRef, EnCl, Iab, Hall角度
    │     出力: Vabc_out[3], IqFb
    │
    ├─ 9. データロガー (100Hz, リングバッファ500サンプル)
    │
    └─ 10. PWM電圧補償 + デューティ更新
          V_dc補償: duty = 0.5 + (duty-0.5) × 18.0/battery_voltage
          inverter.V_dc = battery_voltage (リアルタイム更新)
          timer counts = PWMPeriod(6000) × Vabc_out
          クランプ: 0～6000
          R_GPT_THREE_PHASE_DutyCycleSet()
```

### 5.2 1msタイマーコールバック: One_ms_Int() [1kHz]

```
One_ms_Int()
    │
    ├─ 1. 制御モード選択 (control_mode)
    │     mode 0: SpeedControl_step() → IdqRef, EnCl
    │       入力: Enable, SpeedRefIn_PU, SpeedFb_Hall_PU, IqFb, Mode
    │       出力: IdqRef[2], SpeedRefFinal_PU, EnCl
    │     mode 1: トルク直接制御
    │       IdqRef[0]=0, IdqRef[1]=torque_ref_iq (±0.3 PUクランプ)
    │
    ├─ 2. 電源スイッチ監視 (DI_PON)
    │     3秒長押し → Enable=0, PWM=50%, LATCH_OFF出力
    │
    ├─ 3. 保護監視
    │     バッテリー電圧: <14V→警告, <12V→停止
    │     温度(AN2,AN3): >70°C→警告, >80°C→制限, >90°C→停止
    │     → protection_state, output_derating 更新
    │
    ├─ 4. スイッチ入力 (デバウンス30ms)
    │     IN1: assist_level サイクル (0→1→2→0)
    │     IN2: turbo_mode トグル
    │
    └─ 5. LED制御
          Power LED: 緑=正常, 赤=異常, 赤点滅=警告
          Turbo LED: ターボ時点灯
          Assist LED: 現在レベルのみ点灯
```

## 8. 状態マシン

### 8.1 速度制御状態マシン (FOCSpeedControl.c)

```
                Enable=1 && Mode>=2
  [Init] ───────────────────────> [Run/OpenLoop]
    │                                │
    │                                │ 999ms経過 &&
    │                                │ SpeedFb > 0.09 PU &&
    │                                │ SpeedRef >= 0.15 PU
    │                                ↓
    │                            [Run/ClosedLoopTemp]
    │                                │
    │                                │ 999ms経過
    │                                ↓
    │                            [Run/ClosedLoop]
    │                                │
```

| 状態 | SpeedRefOut | EnCl | Iq出力制限 | 備考 |

| ClosedLoop | SpeedRef | true | ±0.3 PU | 通常運転 |

## 13. 既知の制限事項

1. **電流Ki無効化**: 電流PIのKi>0で発振。原因未特定（サンプリング遅延、ホールセンサ角度精度、またはSimulink生成コードの初期化問題の可能性）
2. ~~**ADCチャネル未検証**~~ → 解決済み: Group 0統合、physical_channelマッチング実装、Unit 0/1の物理制約解明
3. **LEDピン未検証**: LED出力ピン割り当ては仕様書と回路図からの推定。実機確認が必要
4. **output_derating未接続**: output_derating変数は計算されるが、実際のPWM出力には未反映（速度指令へのスケーリング等が必要）
5. **DRV8302 SPIレジスタ未設定**: デフォルト設定で動作中。OCP閾値等のカスタマイズ未実施
6. **hal_data.c手編集3箇所**: FSP再生成時に上書きされる（u2_maximum_period=2000, f_pwm_carrier_freq=10.0, f4_start_speed_rad=0.0）
