# フェールセーフ仕様書

**プロジェクト:** pj:26-001 maxon EC45 flat モータードライバ
**作成日:** 2026-03-22
**重要度:** 最高（安全関連）

---

## 1. 概要

本ドキュメントは、モータードライバ基板の全保護機能を体系的に記述する。
過去の過電流事故（2026-03-22、16A×7秒、モーター発煙・基板②損傷）を受け、
ソフトウェア・ハードウェア両面で多重防護を構築した。

### 設計方針

- **多重防護**: 単一故障で破壊に至らない
- **フェールセーフ**: 異常検出時は停止側に倒す
- **ラッチ**: 重大故障は自動復帰しない（明示的リセットが必要）
- **デレーティング**: 限界到達前に出力を段階的に制限

### 保護対象

| 対象 | 仕様 | 絶対最大定格 |
|------|------|------------|
| モーター (maxon EC45 flat 651614) | 連続 3.29A / 4750rpm | 巻線 125°C |
| ゲートドライバ (DRV8302) | 60V / 相電流定格 | OCP/OVP 内蔵 |
| バッテリー (Makita BL1820B) | 18V nom / 14-20V | 過放電/過充電保護 (BMS) |
| 基板 | NTC 監視 (インバータ/回生) | 実装部品定格依存 |

## 2. 保護階層一覧

```
┌─────────────────────────────────────────────────┐
│              Level 0: ハードウェア保護            │
│   DRV8302 OCP/OVP, 回生回路, nFAULT             │
│   → ソフトウェア不要。電気的に動作。             │
├─────────────────────────────────────────────────┤
│              Level 1: 瞬時電流保護 (100μs)       │
│   Raw OC: LPF前の生電流チェック                  │
│   → 1 ADCサイクルで即停止                        │
├─────────────────────────────────────────────────┤
│              Level 2: 電流保護 (~1ms)            │
│   Filtered OC: LPF後の電流チェック               │
│   → ノイズ耐性あり、持続的過電流を検出           │
├─────────────────────────────────────────────────┤
│              Level 3: 熱保護 (~10秒オーダー)     │

└─────────────────────────────────────────────────┘
```

## 3. Level 0: ハードウェア保護

ソフトウェアに依存せず動作する。MCU 故障時の最終防壁。

### 3.1 DRV8302 ゲートドライバ保護

| 機能 | 条件 | 動作 | 復帰 |
|------|------|------|------|
| OCP (過電流) | 相電流超過 | nFAULT=LOW, ゲート遮断 | EN_GATE リセット |
| OVP (過電圧) | Vds > 60V | nFAULT=LOW | 自動復帰 |
| UVLO | Vdd 不足 | ゲート遮断 | 電圧回復で復帰 |
| 過熱保護 | ジャンクション温度超過 | nFAULT=LOW | 温度低下で復帰 |

**ソフトウェア連携:**
- nFAULT ピン (PB00) を ADC コールバック内で毎 100μs 監視
- fault 検出 → `drv8302_fault_latched=1` (ラッチ、電源サイクルのみリセット)
- ラッチ中は Enable=0, PWM=50% を ADC コールバック内で強制

**実装箇所:** `hal_entry.c` ADC コールバック内 (10kHz)

### 3.2 回生回路 (ハードウェア自動)

| 項目 | 仕様 |
|------|------|
| トリガ電圧 | 39V (コンパレータ UPC277G2) |
| 回生抵抗 | 20Ω × 2 並列 = 10Ω |
| 回生電力 | 最大 152W (39V/10Ω) |
| MOSFET | TPH2R506PL (60V/210A) |
| 逆流防止 | ダイオードによりバッテリーへの帰還なし |

**動作:** Vbus > 39V でコンパレータが自動的に回生 MOSFET を ON。
ソフトウェア不要。MCU 停止中でも動作する。

**詳細:** [回生回路設計書.md](回生回路設計書.md)

## 4. Level 1: 瞬時電流保護 (Raw OC)

**目的:** LPF による遅延なしで、極端な電流スパイクを即座に検出・停止する。

| 項目 | 値 |
|------|-----|
| 対象信号 | Id_raw, Iq_raw (Park変換直後、LPF前) |
| 閾値 | **0.35 PU = 5.8A** |
| 応答時間 | **100μs** (1 ADC サイクル) |
| 実行レート | 10kHz (ADC コールバック内) |
| 動作 | Enable=0, PWM=50%, overcurrent_fault=1 (ラッチ) |
| debug_enable_off_src | **7** |

**設計根拠:**
- 閾値 0.35 PU は定格 (0.20 PU) の 175%、Filtered OC (0.25 PU) の 140%
- LPF 前なのでノイズを含む → 閾値を高めに設定し誤トリップ回避
- Hallセンサ故障による角度ジャンプ → 座標変換の不連続 → 大電流スパイク を捕捉

**実装箇所:** `hal_entry.c` ADC コールバック内、Park 変換直後・LPF 前

## 5. Level 2: 電流保護 (Filtered OC)

**目的:** ノイズ耐性のある電流監視で、持続的な過電流を検出する。

| 項目 | 値 |
|------|-----|
| 対象信号 | Id_fb, Iq_fb_val (LPF α=0.1, カットオフ ~160Hz) |
| 閾値 | **0.25 PU = 4.1A** (定格の 125%) |
| 応答時間 | **~1ms** (LPF 時定数 ~10 サンプル) |
| 実行レート | 10kHz (ADC コールバック内) |
| 動作 | Enable=0, PWM=50%, 積分器リセット, overcurrent_fault=1 (ラッチ) |
| debug_enable_off_src | **6** |

**設計根拠:**
- 閾値 0.25 PU は定格 3.29A の 125%
- LPF 後なのでノイズによる誤トリップなし
- 積分器暴走、PI 発振など「徐々に電流が上昇する」パターンを確実に捕捉

**実装箇所:** `hal_entry.c` ADC コールバック内、LPF 後

## 6. Level 3: 熱保護

### 6.1 I²t モーター巻線熱保護

**目的:** NTC で直接測定できないモーター巻線温度を、電流の二乗積分で推定し保護する。

**熱モデル (1次遅れ):**

```
dE/dt = I² − E/τ_w

E : 熱エネルギー蓄積量 [PU²·s]
I² : Id² + Iq² (実測フィードバック電流)
τ_w : 巻線熱時定数 = 43.1s (maxon データシート)

定常状態: E_eq = I² × τ_w
トリップ: E > I_rated² × τ_w = 0.04 × 43.1 = 1.724 PU²·s
```

| 段階 | i2t_ratio | 推定巻線温度上昇 | output_derating | 動作 |
|------|-----------|----------------|-----------------|------|
| 正常 | < 70% | < 70°C | 1.0 (制限なし) | — |
| Warning | 70% | ~70°C | 1.0 → 0.5 (線形) | protection_state=1 |
| Derating | 85% | ~85°C | 0.5 → 0.0 (線形) | protection_state=2 |
| **Trip** | **100%** | **~100°C** | **0.0** | **protection_state=3, 停止** |

**デレーティングの効果 (負帰還ループ):**

```
I²t 上昇 → derating 増加 → トルク指令低減 → 実電流低下 → I²t 冷却
→ 自動的に安全な平衡点に収束
```

**過負荷時のトリップ時間 (デレーティングなしの理論値):**

| 電流 | 定格比 | トリップまでの時間 |
|------|--------|-----------------|
| 3.29A (0.20PU) | 100% | ∞ (定常で閾値と一致) |
| 4.1A (0.25PU) | 125% | ~77s (但し Filtered OC で即停止) |
| 4.9A (0.30PU) | 150% | ~35s |
| 6.6A (0.40PU) | 200% | ~14s |

**冷却特性:**
- 停止時: E(t) = E₀ × exp(−t/43.1)
- 半減期: 43.1 × ln2 = 29.9 秒

**E0 リセット動作:**
- overcurrent_fault クリア
- i2t_accumulator を 50% に低減 (0 にしない — モーターは冷えていない)
- 即座に再起動しても derating zone (70% 以下) で保護される

**BLE モニタリング:** `i2t_ratio` (var_registry, read-only) で現在の熱負荷を確認可能

**実装箇所:** `hal_entry.c` One_ms_Int 内 (1kHz)

### 6.2 基板温度保護 (NTC サーミスタ)

| センサ | 監視対象 | ADC チャネル |
|--------|---------|-------------|
| TH1 | インバータ部 (temp_inverter) | AN2 |
| TH2 | 回生抵抗部 (temp_regen) | AN3 |

| 段階 | 温度 | output_derating | 動作 |
|------|------|-----------------|------|
| Warning | ≥ 70°C | 0.7 | protection_state=1 |
| Derating | ≥ 80°C | 0.3 | protection_state=2 |
| **Shutdown** | **≥ 90°C** | **0.0** | **protection_state=3, 停止** |

**output_derating 適用箇所:**
- トルク制御: `IdqRef[1] = iq_cmd × output_derating`
- 速度制御: `IdqRef[1] *= output_derating` (SpeedControl_step 出力後)

**実装箇所:** `hal_entry.c` One_ms_Int 内 (1kHz)

## 8. Level 5: 構造的制限

ソフトウェアバグや異常パラメータが入力されても、物理的に出力が制限される構造。

### 8.1 電流 PI 積分器クランプ

| 項目 | 値 | 意味 |
|------|-----|------|
| Id_integral | ±0.05 PU | 停止モータ最大電流 4.7A (0.28PU) |
| Iq_integral | ±0.05 PU | Filtered OC (0.25PU) 以下に収まる |

**設計根拠:**
```
停止モータ最大電流 = (Kp×error_max + integral_max) × Vbase / Rs
= (0.5×0.2 + 0.05) × 9V / 0.2865Ω = 4.7A = 0.28 PU
→ Filtered OC (0.25PU) でトリップするが、Raw OC (0.35PU) には届かない
```

### 8.2 電圧円リミッタ

| 項目 | 値 |
|------|-----|
| V_limit | 0.95 PU |
| 動作 | |Vdq| > 0.95 → 比例縮小 |
| Back-calculation | 飽和分を積分器から減算 |

### 8.3 速度 PI サチュレーション

| 項目 | 値 |
|------|-----|
| IdqRef[1] 上限 | ±0.194 PU (3.2A) — Simulink 生成コード内 |
| アンチワインドアップ | クランピング方式 (飽和時は積分停止) |

### 8.4 VDC 補償制限

| 項目 | 値 |
|------|-----|
| vdc_scale 上限 | 1.5 (12V まで対応) |
| Duty clamp | 0.02 ~ 0.98 (SVPWM バランス維持) |
| PWM duty 最終クランプ | 0 ~ 6000 counts |

### 8.5 BLE コマンド安全クランプ

| パラメータ | 制限 | 根拠 |
|-----------|------|------|
| torque_ref_iq | ±OC_TRIP_PU (±0.25) | 瞬時過電流防止 |
| torque_ref_iq_max | 0 ~ OC_TRIP_PU | 同上 |
| Ki_id, Ki_iq | 0 ~ 50 | 積分器暴走防止 |
| speed_ref_rpm | ±1000 | M コマンドクランプ |
| torque_max_speed_rpm | 0 ~ 4500 | モーター定格 4750rpm 以下 |

### 9.2 単一故障解析

| 故障点 | 残存保護 | モーター/基板は安全か |
|--------|---------|-------------------|
| Raw OC 故障 (閾値ミス等) | Filtered OC → I²t → DRV OCP | 安全 |
| Filtered OC 故障 | Raw OC → I²t → DRV OCP | 安全 |
| I²t 故障 (accumulator 異常) | Raw OC → Filtered OC → NTC | 安全 |
| NTC 断線 (温度=異常値) | I²t → OC 保護 | 安全 (要確認: 断線時の読み値) |
| ADC 故障 (電流読み=0) | **DRV8302 OCP のみ** | HW 依存 |
| DRV8302 故障 | ソフト OC → I²t | 部分的 (HW OCP 喪失) |
| 回生回路故障 | DRV8302 OVP | 安全 (但し 60V まで上昇) |

**結論:** ADC + DRV8302 の同時故障以外では破壊に至らない。

## 12. 過去の事故と教訓

### 2026-03-22: 過電流事故

| 項目 | 内容 |
|------|------|
| 状況 | Ki_iq=5, back-EMF FF 有効, モーター停止状態 |
| 原因 | 積分器が無制限に蓄積 → Vq≈0.5PU → 停止モータに 16A |
| 持続時間 | 7 秒以上 |
| 被害 | モーター発煙、基板② DRV8302 損傷 |
| 根本原因 | ソフトウェア過電流保護が未実装だった |

**再発防止策 (全て実装済み):**

1. Raw OC (Level 1) — LPF 前の瞬時チェック
2. Filtered OC (Level 2) — LPF 後の持続チェック
3. I²t 熱保護 (Level 3) — 巻線熱モデルによるデレーティング
4. 積分器クランプ ±0.05 (Level 5) — 停止モータ電流の物理的上限
5. BLE パラメータ安全クランプ (Level 5) — 危険な Ki/Iq_max の制限

**同一事故の再現可能性: 不可能。**
積分器クランプ (±0.05) により停止モータ最大電流は 4.7A。
Filtered OC (0.25PU=4.1A) が先にトリップする。
仮に Filtered OC が失敗しても、I²t が ~35秒でトリップする。
仮に I²t も失敗しても、DRV8302 OCP がハードウェアで停止する。

| 3 | I²t warning | T60 連続 60秒 → i2t_ratio 監視 | 70% で derating 開始 |
| 4 | I²t trip | T100 連続 → i2t_ratio 監視 | 100% で停止, src=8 |
| 5 | E0 リセット | I²t trip 後に E0 → i2t_ratio 確認 | 50% に低減 |
| 6 | 温度保護 | (外部加熱テスト) | 70/80/90°C で動作 |
| 7 | 低電圧 | PC adapter で低電圧シミュレート | 14V warning, 12V cutoff |
| 8 | nFAULT | (基板② で既に確認済み) | ラッチ停止 |

### 13.2 モーター動作確認 (安全確認後)

1. PC adapter (19V/2.37A=45W) + 基板① で実施
2. P-only (Ki=0), torque_ref_iq=0.01 PU (最小) から開始
3. i2t_ratio, IqFb, overcurrent_fault を BLE で常時監視
4. 異常があれば即座に E0 + 電源OFF
