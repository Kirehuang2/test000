# 回生回路設計書

**プロジェクト:** maxon EC45 flat 制御用モータードライバ基板
**作成日:** 2026-02-01
**重要度:** 高

---

## 1. 概要

本ドキュメントは、モーター減速時の回生電力処理を行う回生回路（ブレーキ抵抗回路）の設計仕様を記述します。

### 目的

- モーター減速時の逆起電圧による過電圧を防止
- バッテリー電圧を安全範囲内に維持
- 電源回路の保護

### 動作原理

```
モーター減速
    ↓
逆起電圧発生（モーターが発電機として動作）
    ↓
バス電圧上昇
    ↓
コンパレータが過電圧検出
    ↓
回生MOSFET ON
    ↓
回生抵抗で電力を熱に変換
    ↓
バス電圧を安全範囲に維持
```

## 3. 動作解析

### 3.1 トリガ電圧の計算

**分圧回路（バス電圧検出）:**
```
V_comp(+) = V_bus × R_div2 / (R_div1 + R_div2)
          = V_bus × 15kΩ / (180kΩ + 15kΩ)
          = V_bus × 15 / 195
          = V_bus × 0.0769
```

**基準電圧（コンパレータ - 入力）:**
```
V_ref = 3.3V × R_ref1 / (R_ref2 + R_ref1)
      = 3.3V × 100kΩ / (10kΩ + 100kΩ)
      = 3.3V × 100 / 110
      = 3.0V
```

**トリガ電圧（V_comp(+) = V_ref のとき）:**
```
V_bus × 0.0769 = 3.0V
V_bus_trigger = 3.0V / 0.0769
              = 39V
```

✅ **設計確認済み:**
**トリガ電圧39Vは正しい設計です。**

### 動作原理

**重要:** トリガ電圧39Vは、**バッテリー電圧 + モーター逆起電圧の合計**です。

**通常動作時（モーター駆動中）:**
```
バス電圧 = バッテリー電圧のみ
        = 14～20V
→ 回生回路は動作しない（39V未満）
```

**ブレーキ動作時（モーター発電）:**
```
バス電圧 = バッテリー電圧 + 逆起電圧
        = 20V（満充電） + 20V（例: モーター発電）
        = 40V
→ 39V超過で回生回路が動作
→ 回生抵抗で電力を消費
→ バス電圧を39V以下に維持
```

**設計根拠:**
- バッテリー最大電圧: 20V
- 許容逆起電圧: 約19V
- トリガ電圧: 39V（20V + 19V）
- 保護対象の耐圧: DRV8302（60V）、電解コンデンサ（25V定格）

**安全マージン:**
- トリガ電圧39Vは、各部品の耐圧に対して十分な余裕あり
  - DRV8302: 60V定格（65%使用）
  - 電解コンデンサ: 50V定格（78%使用）
  - TPH2R506PL: 60V定格（65%使用）
- 全ての主要部品で適切な安全マージンを確保

### 3.2 電解コンデンサの耐圧確認

✅ **耐圧仕様の確認:**

**電解コンデンサの仕様:**
- 型番: UCD1H331MNL6GS
- 定格電圧: **50V**
- 容量: 330µF
- 使用個数: 3個並列
- 合計容量: 990µF

**耐圧評価:**
```
トリガ電圧: 39V
コンデンサ定格: 50V
電圧使用率: 39V / 50V = 0.78 (78%)
安全マージン: (50V - 39V) / 50V = 22%
```

**設計評価:**
✅ **適切な設計です**

- 定格電圧50Vに対して最大39Vの使用は適正範囲内
- 安全マージン22%を確保
- 一般的な推奨使用率80%以下を満たす
- 温度上昇やリップル電流による定格低下を考慮しても十分な余裕

**長期信頼性:**
- 電解コンデンサは定格電圧の70～80%で使用すると寿命が最大化
- 本設計（78%使用）は理想的な使用範囲
- UCD1Hシリーズは低ESR・長寿命タイプで適切な選定

**念のための確認項目:**
- [ ] 実測での最大バス電圧（ブレーキ時）が39V以下であることの確認
- [ ] コンデンサのリップル電流定格が使用条件に適合していることの確認
- [ ] 周囲温度と許容温度範囲の確認

### 3.3 回生抵抗の電力計算

**回生抵抗の合成抵抗:**
```
R_total = R_brake1 || R_brake2
        = 20Ω || 20Ω
        = 10Ω
```

**バス電圧39V（トリガ電圧）で回生動作時:**
```
I_regen = V_bus / R_total
        = 39V / 10Ω
        = 3.9A

P_total = V_bus × I_regen
        = 39V × 3.9A
        = 152.1W

各抵抗の電力:
P_each = P_total / 2
       = 152.1W / 2
       = 76.1W
```

**必要な抵抗定格:**
- 定格電力: 100W以上（安全率1.3倍）
- 推奨: 150W（安全率2倍）
- **注意:** 回生動作はパルス的（短時間ON/OFF繰り返し）のため、
  連続定格よりパルス定格で評価可能。ただし連続回生シナリオでは要注意。

**連続回生時の発熱:**
長時間の下り坂などで連続回生が発生する場合、発熱が問題になる可能性があります。
→ サーミスタ（TH2）による温度監視が重要

### 3.4 MOSFET選定の妥当性

**TPH2R506PL仕様:**
- V_DSS: 60V
- I_D: 210A @ Tc=25°C
- R_DS(on): 2.5mΩ @ V_GS=10V

**回生動作時の条件:**
- ドレイン-ソース間電圧: 約39V（トリガ電圧時）
- ドレイン電流: 3.9A（回生電流）

**MOSFET損失:**
```
P_MOSFET = I_D² × R_DS(on)
         = (3.9A)² × 2.5mΩ
         = 38mW
```

→ MOSFET自体の発熱は非常に小さく、問題なし
→ ただしVDS=39VはVDSS=60Vの65%で、安全マージンは確保済み

## 4. 部品選定根拠

### 4.1 コンパレータ（UPC277G2）

**選定理由:**
- 単電源動作（3.3V～15V対応）
- 汎用コンパレータ
- 低コスト

**仕様:**
- 電源電圧: 3V～15V
- 入力オフセット電圧: ±5mV (typ)
- 応答時間: **[要確認]** µs
- 出力タイプ: オープンコレクタ

**懸念事項:**
- [ ] 応答速度が十分か確認（過電圧の立ち上がり速度に対して）
- [ ] ヒステリシスの有無・必要性

### 4.2 回生抵抗

**必要仕様:**
- 抵抗値: 20Ω × 2個（並列で10Ω）
- 定格電力: 30W以上（推奨50W）
- タイプ: セメント抵抗 or アルミハウジング抵抗

**推奨部品例:**
- セメント抵抗: 50W品
- アルミハウジング抵抗: 放熱性良好

**取付注意:**
- 十分な放熱スペース確保
- サーミスタを抵抗近傍に配置
- エアフロー考慮

### 4.3 分圧抵抗

**高精度抵抗の必要性:**
トリガ電圧の精度に直結するため、1%精度以上の抵抗を推奨

**推奨仕様:**
- 精度: 1%以上
- 温度係数: ±100ppm/°C以下

## 5. 動作シミュレーション

### 5.1 想定動作シナリオ

#### シナリオ1: 急減速時

```
時刻  0ms: モーター全速力回転（バッテリー18V）
時刻 10ms: 急ブレーキ（モーター逆起電力発生）
時刻 20ms: バス電圧上昇開始 (18V → 25V)
時刻 30ms: バス電圧39V到達 → コンパレータトリガ
時刻 31ms: 回生MOSFET ON
時刻 32ms: 回生抵抗に電流流れ始め
時刻 50ms: バス電圧が39V以下に低下 → コンパレータOFF
時刻 51ms: 回生MOSFET OFF
```

**期待される動作:**
- バス電圧が39V以上に上昇しない（トリガ電圧 = 39V）
- 回生抵抗の温度上昇が許容範囲内

#### シナリオ2: 長時間下り坂

```
時刻    0s: 下り坂開始
時刻   10s: 回生動作開始（ON/OFF繰り返し）
時刻   30s: 回生抵抗温度70°C到達 → 警告
時刻   60s: 回生抵抗温度80°C到達 → 出力制限
時刻  120s: 平地に戻る → 温度降下開始
```

**期待される動作:**
- サーミスタ（AN3）による温度監視
- 過熱時は出力制限で回生頻度を低減
- ユーザーへの警告（LED点滅等）

### 5.2 異常動作シナリオ

#### 異常1: コンパレータ故障

**現象:** コンパレータ出力がHigh固定
**結果:** 回生MOSFET常時OFF → 過電圧保護なし
**対策:**
- DRV8302の過電圧保護（OVP）が動作
- MCUでバッテリー電圧監視（AN1）

#### 異常2: 回生MOSFET短絡

**現象:** MOSFET常時ON
**結果:** 回生抵抗が常時接続 → バッテリー消耗、抵抗過熱
**対策:**
- サーミスタ（AN3）で異常温度検出
- バッテリー電流異常検出

#### 異常3: 回生抵抗断線

**現象:** 抵抗断線 or 接触不良
**結果:** 回生機能喪失 → 過電圧
**対策:**
- DRV8302のOVP動作
- MCUでバッテリー電圧異常検出

## 6. テスト方法

### 6.1 初期動作確認

#### Test 1: コンパレータ動作確認

**目的:** コンパレータのトリガ電圧確認

**手順:**
1. 基板に電源投入（モーター未接続）
2. バッテリー電源を可変電源に置き換え
3. 電源電圧を0Vから徐々に上昇
4. コンパレータ出力電圧を測定
5. トリガ電圧を記録

**期待値:**
- トリガ電圧: 39V（分圧比 15k/(180k+15k)、基準電圧 3.0V から算出）
- ヒステリシス: **[要確認]** V（正帰還抵抗なしの場合、ほぼ0）

#### Test 2: 回生抵抗電流測定

**目的:** 回生抵抗の電流・電力測定

**手順:**
1. 回生回路に電流計を挿入
2. 可変電源を22Vに設定
3. コンパレータを強制トリガ（テストピン使用）
4. 回生電流を測定

**期待値:**
- 回生電流: 3.9A ± 10%（39V / 10Ω）
- 回生抵抗温度上昇: 安全範囲内

### 6.2 モーター接続テスト

#### Test 3: 実負荷回生テスト

**目的:** 実際のモーター減速時の回生動作確認

**手順:**
1. モーター接続、無負荷状態
2. モーターを最高回転数まで加速
3. 急停止コマンド発行
4. オシロスコープでバス電圧波形を観測
5. 回生動作の有無を確認

**測定項目:**
- バス電圧のピーク値
- 回生MOSFET ON時間
- 回生抵抗温度上昇

**期待値:**
- バス電圧ピーク: 39V以下（トリガ電圧で制限）
- 回生動作: トリガ電圧（39V）到達時のみ
- 抵抗温度: 60°C以下（短時間動作）

#### Test 4: 連続回生テスト

**目的:** 長時間回生時の熱的安定性確認

**手順:**
1. モーターを繰り返し加減速（ON 5秒、OFF 5秒を繰り返し）
2. 10分間継続
3. サーミスタ温度をモニタリング
4. 回生抵抗の目視温度チェック（非接触温度計）

**測定項目:**
- サーミスタ温度（AN3）
- 回生抵抗表面温度
- 基板周辺温度

**期待値:**
- サーミスタ温度: 80°C以下
- 回生抵抗温度: 100°C以下
- 基板温度: 60°C以下

### 6.3 異常系テスト

#### Test 5: 過電圧注入テスト

**目的:** 異常電圧時の保護動作確認

**手順:**
1. 可変電源でバッテリー電圧をシミュレート
2. 電圧を39V付近まで上昇
3. 回生回路の動作を確認（コンパレータ出力変化）
4. さらに50V付近まで上昇（DRV8302 OVP確認）
5. DRV8302のOVP動作を確認

**期待値:**
- 39V到達時: 回生回路動作（コンパレータトリガ）
- 50V以上: DRV8302 OVP動作（nFAULT信号Low）

#### Test 6: サーミスタ監視テスト

**目的:** 過熱保護動作確認

**手順:**
1. サーミスタ周辺を外部加熱（ヒートガン等）
2. AN3の電圧変化をモニタリング
3. MCUソフトウェアの過熱保護動作を確認

**期待値:**
- 70°C到達時: 警告表示（LED等）
- 90°C到達時: 出力制限 or 緊急停止

## 7. 設計検討事項

### 7.1 トリガ電圧の確認

**計算結果:**
- 分圧比: 15k/(180k+15k) = 0.0769
- 基準電圧: 3.3V × 100k/(10k+100k) = 3.0V
- トリガ電圧: 3.0V / 0.0769 = **39V**

**設計意図:**
- バッテリー最大電圧（20V）+ 逆起電圧（最大19V）の合計がトリガ電圧
- 通常運転時（14〜20V）では回生回路は動作しない
- モーター減速時の逆起電圧でバス電圧が39Vを超えた場合のみ動作

**検討が必要:**
- [ ] 実測によるトリガ電圧確認（39V付近であることを確認）
- [ ] ヒステリシスの追加検討（チャタリング防止）

### 7.2 ヒステリシスの必要性

**問題:**
ヒステリシスがない場合、トリガ電圧付近でチャタリング（ON/OFF繰り返し）が発生する可能性

**対策:**
正帰還抵抗を追加してヒステリシスを設定

**推奨ヒステリシス:**
- 0.5～1V程度

### 7.3 回生抵抗の放熱

**現状:**
- セメント抵抗 or アルミハウジング抵抗
- ヒートシンクなし

**検討事項:**
- [ ] 連続回生時の温度上昇が許容範囲内か
- [ ] 基板実装位置の最適化（エアフロー）
- [ ] 放熱パッドの追加
- [ ] 必要に応じてヒートシンク追加

## 8. ソフトウェア連携

### 8.1 MCUでの監視項目

| 信号 | 監視内容 | 異常検出条件 | 対応動作 |
|------|---------|-------------|---------|
| AN1 | バッテリー電圧 | 39V以上 | 警告、出力制限 |
| AN3 | 回生抵抗温度 | 80°C以上 | 出力制限 |
| AN3 | 回生抵抗温度 | 90°C以上 | 緊急停止 |
| nFAULT | DRV8302故障 | Low検出 | 緊急停止 |

### 8.2 推奨保護ロジック

```
// 疑似コード
void regeneration_monitor(void) {
    float v_bat = read_adc(AN1);
    float t_regen = read_temperature(AN3);

    // 過電圧検出（トリガ電圧39Vの手前で警告）
    if (v_bat > 35.0) {
        set_warning(WARNING_OVERVOLT);
        limit_output(0.8);  // 80%に制限
    }

    // 回生抵抗過熱検出
    if (t_regen > 80.0 && t_regen < 90.0) {
        set_warning(WARNING_REGEN_HOT);
        limit_output(0.5);  // 50%に制限
    } else if (t_regen >= 90.0) {
        emergency_stop();
        set_error(ERROR_OVERHEAT);
    }
}
```

## 9. 改善案・将来検討

### 9.1 PWM制御への変更

**現状:** ON/OFF制御（バンバン制御）
**改善案:** PWM制御でより滑らかな電圧制御

**メリット:**
- 電圧リップルの低減
- 回生抵抗の温度上昇の平準化
- ノイズの低減

**デメリット:**
- 制御回路の複雑化
- MCUリソースの追加必要

### 9.2 回生エネルギーのバッテリー充電

**現状:** 抵抗で熱に変換（エネルギー損失）
**改善案:** 昇圧回路でバッテリーに充電

**メリット:**
- エネルギー回生による効率向上
- 回生抵抗の発熱削減

**デメリット:**
- 回路の大幅な追加（昇圧コンバータ、充電制御）
- コスト増加
- バッテリー満充電時の対応が必要
