## 1. 概要

### 1.1 システム概要
本システムは、ワイヤ巻取式1軸サーボバランサの制御システムである。
0kg〜30kgの荷物を吊り下げ、約2kgの操作力で上昇・下降操作を可能とする「ふわふわ」とした操作感を実現する。

### 1.2 動作概要
```
[接地状態] → [電源投入] → [ボタン操作で昇降] → [ボタン離すと静止＋外力追従]
```

### 1.3 設計目標
- 遠藤工業株式会社のサーボバランサーのような軽い操作感
- 約2kgの外力で荷物を上下に操作可能
- ボタン操作時は一定速度で昇降

## 4. 設計計算

### 4.1 トルク計算

#### 4.1.1 出力軸（ドラム軸）トルク
```
荷物によるトルク T_load = M × g × r

最小荷重（5kg）:  T_load_min = 5 × 9.81 × 0.009 = 0.441 Nm
最大荷重（30kg）: T_load_max = 30 × 9.81 × 0.009 = 2.649 Nm
```

#### 4.1.2 モーター軸トルク
```
モーター軸トルク T_motor = T_load / N

最小荷重時: T_motor_min = 0.441 / 15.04 = 0.029 Nm = 29.3 mNm
最大荷重時: T_motor_max = 2.649 / 15.04 = 0.176 Nm = 176.1 mNm
```

#### 4.1.3 必要電流
```
モーター電流 I = T_motor / Kt

最小荷重時: I_min = 0.0293 / 0.0404 = 0.73 A
最大荷重時: I_max = 0.1761 / 0.0404 = 4.36 A
```

#### 4.1.4 操作力によるトルク変化
```
操作力 F_op = 2kg × 9.81 = 19.6 N

出力軸トルク変化: ΔT_load = 19.6 × 0.009 = 0.176 Nm
モーター軸トルク変化: ΔT_motor = 0.176 / 15.04 = 0.0117 Nm = 11.7 mNm
電流変化: ΔI = 0.0117 / 0.0404 = 0.29 A
```

### 4.2 速度計算

#### 4.2.1 追従速度時のモーター回転数
```
線速度 v = 0.03 m/s（3cm/sec）
ドラム角速度 ω_drum = v / r = 0.03 / 0.009 = 3.33 rad/s
モーター角速度 ω_motor = ω_drum × N = 3.33 × 15.04 = 50.1 rad/s
モーター回転数 n_motor = ω_motor × 60 / (2π) = 478 rpm
```

#### 4.2.2 必要電圧（最大荷重・追従速度時）
```
逆起電力 E = ω_motor / Ke = 478 / 236 = 2.03 V
抵抗による電圧降下 V_R = I × R = 4.36 × 0.573 = 2.50 V
必要電圧 V_total ≈ E + V_R = 4.53 V

→ バッテリー電圧14V以上で十分余裕あり
```

### 4.3 ワイヤ・ドラム計算

#### 4.3.1 巻き取り量
```
1回転あたりの巻取長さ L_rev = 2π × r = 2π × 9 = 56.5 mm
ストローク1mに必要な回転数 = 1000 / 56.5 = 17.7 回転
```

#### 4.3.2 ドラム幅
```
必要ドラム幅 = 17.7 × 1.5mm(ワイヤ径) = 26.6 mm
余裕を含めた推奨幅 = 35 mm
```

#### 4.3.3 ワイヤ安全率
```
最大荷重 = 30kg × 9.81 = 294 N
ワイヤ破断荷重 = 180kgf = 1765 N
安全率 = 1765 / 294 = 6.0
```

```
│  └─────────┘   └─────────┘   └─────────┘   └─────────┘        │

│       │                           │                            │
```

### 5.2 動作モード

| モード | 条件 | 動作 |
|--------|------|------|
| 上昇モード | 上昇ボタンON | 一定速度（3cm/s）で上昇 |

**状態一覧：**

| 状態 | 値 | 説明 |
|------|-----|------|
| INIT | 0 | 初期化中 |
| BALANCE | 1 | バランスモード（外力追従） |
| UP | 2 | 上昇モード（一定速度上昇） |
| DOWN | 3 | 下降モード（一定速度下降） |
| STABILIZING | 4 | 静止待ち（荷重更新準備） |

**STABILIZING状態の詳細：**
```
【遷移条件】
  IN:  UPモードでボタンOFF
  OUT: |velocity| < 0.005 m/s が 200ms継続

【動作】
  - 速度指令 v_cmd = 0（静止保持）
  - 静止タイマーをカウント
  - 静止確認後、I_motorをサンプリングしてM_estimated更新
  - BALANCE状態へ遷移
```

### 5.4 重力補償制御

#### 5.4.1 基本式
```
重力補償トルク（モーター軸）:
T_grav_comp = (M_load × g × r) / N

重力補償電流:
I_grav_comp = T_grav_comp / Kt = (M_load × g × r) / (N × Kt)
```

#### 5.4.2 荷重推定

**【重要】電流の使い分け**

外力検出を正しく行うため、荷重推定と外力推定で異なる電流を使用する：

| 用途 | 使用電流 | 説明 |
|------|----------|------|
| 荷重推定（M_estimated） | I_load_est | 静止時にサンプリングした電流 |
| 外力推定（F_wire計算） | I_motor | フィルタ前の生電流（リアルタイム） |

**荷重推定方式：上昇ボタン離し→静止時に自動更新**

```
【更新タイミング】
上昇ボタンを離す → 減速 → 静止検出 → 電流サンプリング → M_estimated更新

この瞬間は外力が加わっていないため、純粋に荷物重量のみを反映した電流が得られる
```

**更新条件：**
1. UPモード → BALANCEモードへ遷移（上昇ボタン離し）
2. 速度が静止閾値以下に収束（|v| < 0.005 m/s）
3. 上記状態が安定時間以上継続（200ms以上）

**荷重推定パラメータ：**

| パラメータ | 記号 | 値 | 単位 | 備考 |
|-----------|------|-----|------|------|
| 静止判定速度閾値 | v_stable_th | 0.005 | m/s | 0.5cm/s以下で静止とみなす |
| 静止確認時間 | t_stable | 0.2 | sec | 200ms間静止で確定 |

**荷重推定計算式：**
```
M_estimated = (I_load_est × Kt × N × η) / (g × r)

I_load_est: 静止確認後の電流（200ms間の平均値）
Kt: トルク定数 [Nm/A]
N: 減速比
η: 減速機効率（≒1.0と仮定）
g: 重力加速度 [m/s²]
r: ドラム半径 [m]
```

**初回起動時の動作：**

```
【電源投入シーケンス】
1. 電源投入時、静止状態で電流を測定
2. 測定電流から初期荷重を推定: M_estimated = I_motor × I_to_M_est
3. 重力補償を有効化（荷物が落下しない）
4. 外力追従は無効（load_confirmed = false）
5. 最初の上昇ボタン離し→静止後: M_estimated再更新、外力追従有効化
```

- 電源投入時: 電流測定から M_estimated を初期推定（重力補償のため）
- 外力追従: 最初の上昇操作完了まで無効（誤動作防止）
- 最初の上昇ボタン離し→静止後: M_estimated再更新、外力追従有効化(load_confirmed = true)

### 5.5 外力追従制御（バランスモード）

#### 5.5.1 外力推定

**【重要】生電流（I_motor）を使用すること**

```
ワイヤ張力（リアルタイム）:
F_wire = I_motor × Kt × N / r    ← フィルタ前の生電流を使用

重力（荷重推定値から）:
F_gravity = M_estimated × g       ← 静止時に更新した推定荷重を使用

外力:
F_ext = F_wire - F_gravity
```

**なぜ生電流を使うのか：**
```
例：20kg荷物を吊り下げ中に3kgの力で押し下げた場合

I_motor（リアルタイム）= (20+3)kg相当 = 3.36A
M_estimated（静止時更新）= 20kg（固定）

F_wire = 3.36 × 0.0404 × 15.04 / 0.009 = 227N
F_gravity = 20 × 9.81 = 196N
F_ext = 227 - 196 = 31N ✓ （3kgの押し下げ力を検出）

※もしI_filteredを使うと、時間経過でF_ext→0になり外力検出不可
```

#### 5.5.2 仮想インピーダンス制御

「ふわふわ」感を実現するため、仮想的なバネ・ダンパ系を実装する。

```
仮想運動方程式:
M_v × a + D_v × v = F_ext - F_threshold × sign(F_ext)

M_v: 仮想質量 [kg]（小さいほど軽く感じる）
D_v: 仮想粘性 [N·s/m]（適度にあると安定）
F_threshold: 不感帯閾値 [N]（約20N = 2kgf）
```

#### 5.5.3 パラメータ設計

| パラメータ | 推奨値 | 単位 | 説明 |
|-----------|--------|------|------|
| 仮想質量 M_v | 0.5〜2.0 | kg | 小さいほど軽快 |
| 仮想粘性 D_v | 50〜200 | N·s/m | 大きいほど安定 |
| 不感帯閾値 F_th | 19.6（2kgf） | N | 操作力閾値 |
| 最大追従速度 | 0.03 | m/s | 速度リミット |

#### 5.5.4 速度指令生成
```
if |F_ext| > F_threshold:
    F_effective = F_ext - F_threshold × sign(F_ext)
    v_cmd = v_cmd_prev + (F_effective / M_v - D_v / M_v × v_cmd_prev) × dt
    v_cmd = clamp(v_cmd, -v_max, +v_max)
else:
    v_cmd = 0  // 静止保持
```

### 5.6 ボタン操作モード（上昇/下降）

#### 5.6.1 一定速度制御
```
上昇ボタンON時: v_cmd = +0.03 m/s
下降ボタンON時: v_cmd = -0.03 m/s
```

#### 5.6.2 速度制御ループ
```
速度誤差: e_v = v_cmd - v_actual
PI制御: I_cmd = Kp × e_v + Ki × ∫e_v dt + I_grav_comp

Kp: 速度比例ゲイン
Ki: 速度積分ゲイン
I_grav_comp: 重力補償電流（フィードフォワード）
```

```matlab
% サーボバランサ制御パラメータ初期化スクリプト

%% モーターパラメータ (maxon EC45 flat 651614)
Kt = single(0.0404);              % トルク定数 [Nm/A]
Ke = single(1/236 * 60/(2*pi));   % 逆起電力定数 [V/(rad/s)]
R_motor = single(0.573);          % 端子間抵抗 [Ω]
L_motor = single(0.301e-3);       % 端子間インダクタンス [H]
J_rotor = single(181e-7);         % ローターイナーシャ [kg·m²]
pole_pairs = uint8(8);            % 極対数

%% 機械系パラメータ
gear_ratio = single(15.04);       % 減速比 [-]
drum_radius = single(0.009);      % ドラム半径 [m]
gear_efficiency = single(0.9);    % 減速機効率（概算）

%% 制御パラメータ
dt = single(0.001);               % 制御周期 [sec]
M_virtual = single(1.0);          % 仮想質量 [kg]
D_virtual = single(100.0);        % 仮想粘性 [N·s/m]
F_threshold = single(19.6);       % 不感帯閾値 [N] (2kgf)
v_max = single(0.03);             % 最大追従速度 [m/s]
v_button = single(0.03);          % ボタン操作時速度 [m/s]

%% 速度制御ゲイン
Kp_vel = single(10.0);            % 速度Pゲイン [A/(m/s)]
Ki_vel = single(50.0);            % 速度Iゲイン [A/(m/s)/s]

%% 電流制限
I_max = single(4.36);             % 電流上限 [Arms]
I_min = single(-4.36);            % 電流下限 [Arms]

%% フィルタパラメータ
fc_vel = single(10.0);            % 速度LPFカットオフ周波数 [Hz]
fc_load = single(0.5);            % 荷重推定LPFカットオフ周波数 [Hz]

% 離散LPF係数計算 (1次IIRフィルタ: y = alpha*x + (1-alpha)*y_prev)
alpha_vel = single(2*pi*fc_vel*dt / (2*pi*fc_vel*dt + 1));
alpha_load = single(2*pi*fc_load*dt / (2*pi*fc_load*dt + 1));

%% 物理定数
g = single(9.81);                 % 重力加速度 [m/s²]

%% 変換係数（事前計算）★効率(η)を考慮★
% 電流→ワイヤ張力 変換係数 ※効率を含む
I_to_F = single(Kt * gear_ratio * gear_efficiency / drum_radius);  % [N/A] = 60.8
% ワイヤ張力→電流 変換係数 ※効率を含む
F_to_I = single(drum_radius / (Kt * gear_ratio * gear_efficiency)); % [A/N]
% モーター角速度→ワイヤ線速度 変換係数
omega_to_v = single(drum_radius / gear_ratio);   % [m/s / (rad/s)]
% 荷重→重力補償電流 変換係数 ※効率を含む
M_to_I_grav = single(g * drum_radius / (Kt * gear_ratio * gear_efficiency)); % [A/kg] = 0.1615
% 電流→推定荷重 変換係数 ※効率を含む
I_to_M_est = single(Kt * gear_ratio * gear_efficiency / (g * drum_radius)); % [kg/A] = 6.19

%% 初期値
M_load_init = single(10.0);       % 初期荷重推定値 [kg]（デフォルト）

%% 表示確認

fprintf('最大速度 v_max = %.3f m/s\n', v_max);
```

**内部構成（Signal_Processing サブシステム全体）:**

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                        Signal_Processing サブシステム                            │
│                                                                                 │
│  【入力】              【内部処理】                              【出力】         │
│                                                                                 │
│  Inport 1 ──────→ 速度フィルタ ──→ 単位変換 ──────────────→ Outport 1         │
│  (vel_motor)       (LPF 10Hz)      [rad/s]→[m/s]             (vel_wire)        │
│  [rad/s]                                                      [m/s]            │
│                                                                                 │
│  Inport 2 ──────→ 電流フィルタ ─────────────────────────────→ Outport 2         │
│  (I_motor)         (LPF 0.5Hz)                                (I_filtered)     │
│  [A]                                                          [A]              │
│                                                                                 │
└─────────────────────────────────────────────────────────────────────────────────┘

※重要: vel_motor [rad/s] を vel_wire [m/s] に変換して出力
  変換式: vel_wire = vel_motor × drum_radius / gear_ratio
                   = vel_motor × 0.009 / 15.04
                   = vel_motor × 0.000598
```

**単位変換の必要性:**
```
入力:
  - vel_motor: モーター角速度 [rad/s]
  - 制御で使用する v_cmd: ワイヤ線速度 [m/s]

単位が異なるため、Signal Processing内で変換が必要！

変換係数:
  omega_to_v = drum_radius / gear_ratio
             = 0.009 / 15.04
             = 0.000598 [m/s / (rad/s)]
```

**1次IIRローパスフィルタの構成（速度・電流共通）:**

```
フィルタ式: y[n] = alpha × x[n] + (1 - alpha) × y[n-1]

                        ┌─────────────────────────────────────────┐
                        │                                         │
入力 ───[Gain: alpha]───┐                                         │
                        │                                         │
                       [Add: ++]─────────────────────▶ 出力       │
                        ↑                               │         │
                        │                               │         │
                 [Gain: 1-alpha]                        │         │
                        ↑                               │         │
                        │                               │         │
                   [Unit Delay]◀────────────────────────┘         │
                        │                                         │
                        └─────────────────────────────────────────┘

信号の流れ（番号順）:
  ① 入力 → Gain(alpha) → Add(+入力1)
  ② Add出力 → Outport（出力）
  ③ Add出力 → Unit Delay(z⁻¹) → Gain(1-alpha) → Add(+入力2) ※フィードバック
```

**具体的なブロック配置:**

```
【速度処理】フィルタ(10Hz) + 単位変換

  使用ブロック:
    1. Inport:     Name = vel_motor, Port = 1, 単位 = rad/s
    2. Gain:       Gain = alpha_vel (フィルタ用)
    3. Add:        Inputs = ++
    4. Unit Delay: Sample time = dt (0.001)
    5. Gain:       Gain = 1-alpha_vel (フィルタ用)
    6. Gain:       Gain = omega_to_v (単位変換用) ★追加
    7. Outport:    Name = vel_wire, Port = 1, 単位 = m/s ★名前変更

  接続順序:
    vel_motor [rad/s] → Gain(alpha_vel) → Add(+入力1)
                                            ↓
                                          Add出力 [rad/s]
                                            ↓
                         ┌──────────────────┴──────────────────┐
                         ↓                                     ↓
                   Unit Delay → Gain(1-alpha_vel) → Add(+入力2)
                                                               ↓
                                            Gain(omega_to_v) ★単位変換
                                                               ↓
                                                          vel_wire [m/s]

  ※フィルタ後に単位変換を行う（順序重要）

【電流フィルタ】カットオフ周波数 0.5Hz（荷重推定用、遅いフィルタ）

  使用ブロック:
    1. Inport:     Name = I_motor, Port = 2, 単位 = A
    2. Gain:       Gain = alpha_load
    3. Add:        Inputs = ++
    4. Unit Delay: Sample time = dt (0.001)
    5. Gain:       Gain = 1-alpha_load
    6. Outport:    Name = I_filtered, Port = 2, 単位 = A

  接続順序:
    I_motor [A] → Gain(alpha_load) → Add(+入力1)
                                       ↓
                                     Add出力 → I_filtered [A]
                                       ↓
                                     Unit Delay → Gain(1-alpha_load) → Add(+入力2)
```

**パラメータ（init_parameters.m で計算）:**
```matlab
% 速度フィルタ（カットオフ 10Hz）
alpha_vel = 2*pi*10*0.001 / (2*pi*10*0.001 + 1) = 0.0591

% 電流フィルタ（カットオフ 0.5Hz）← 荷重推定用なので遅い
alpha_load = 2*pi*0.5*0.001 / (2*pi*0.5*0.001 + 1) = 0.00314

% ★単位変換係数（モーター角速度 → ワイヤ線速度）
omega_to_v = drum_radius / gear_ratio
           = 0.009 / 15.04
           = 0.000598  % [m/s / (rad/s)]
```

| Inport 2 | I_motor | single | A | モーター電流（入力） |

```matlab
function [mode, v_cmd_mode, M_estimated, stable_cnt] = mode_controller(...
    btn_up, btn_down, vel_wire, I_motor, mode_prev, M_est_prev, stable_cnt_prev)
%#codegen
% モード制御（状態機械）+ 荷重自動推定
%
% 入力:
%   btn_up          - 上昇ボタン (boolean)
%   btn_down        - 下降ボタン (boolean)
%   vel_wire        - ワイヤ速度 [m/s] (single)
%   I_motor         - モーター電流 [A] (single) ※フィルタ前の生電流
%   mode_prev       - 前回のモード (uint8)
%   M_est_prev      - 前回の荷重推定値 [kg] (single)
%   stable_cnt_prev - 静止カウンタ (uint16)
%
% 出力:
%   mode        - 現在のモード (uint8)
%   v_cmd_mode  - モード別速度指令 [m/s] (single)
%   M_estimated - 荷重推定値 [kg] (single)
%   stable_cnt  - 静止カウンタ (uint16)

    %% モード定義
    MODE_INIT        = uint8(0);
    MODE_BALANCE     = uint8(1);
    MODE_UP          = uint8(2);
    MODE_DOWN        = uint8(3);
    MODE_STABILIZING = uint8(4);

    %% パラメータ
    v_button     = single(0.03);    % ボタン操作時速度 [m/s]
    v_stable_th  = single(0.005);   % 静止判定閾値 [m/s]
    t_stable     = uint16(200);     % 静止確認時間 [ms] = 200回 × 1ms

    % 荷重推定用定数
    Kt         = single(0.0404);    % トルク定数 [Nm/A]
    gear_ratio = single(15.04);     % 減速比
    drum_radius = single(0.009);    % ドラム半径 [m]
    g          = single(9.81);      % 重力加速度 [m/s²]

    %% デフォルト出力
    M_estimated = M_est_prev;       % 荷重は基本的に前回値を維持
    stable_cnt = uint16(0);

    %% 状態遷移ロジック
    switch mode_prev
        case MODE_INIT
            % 初期化 → 即座にBALANCEへ遷移
            mode = MODE_BALANCE;
            v_cmd_mode = single(0);

        case MODE_BALANCE
            % バランスモード
            if btn_up && ~btn_down
                mode = MODE_UP;
                v_cmd_mode = v_button;
            elseif btn_down && ~btn_up
                mode = MODE_DOWN;
                v_cmd_mode = -v_button;
            else
                mode = MODE_BALANCE;
                v_cmd_mode = single(0);  % 外力追従は別ブロックで計算
            end

        case MODE_UP
            % 上昇モード
            if ~btn_up
                % 上昇ボタン離された → STABILIZINGへ（荷重更新のため）
                mode = MODE_STABILIZING;
                v_cmd_mode = single(0);
                stable_cnt = uint16(0);  % カウンタリセット
            else
                mode = MODE_UP;
                v_cmd_mode = v_button;
            end

        case MODE_DOWN
            % 下降モード
            if ~btn_down
                % 下降ボタン離された → BALANCEへ（荷重更新なし）
                mode = MODE_BALANCE;
                v_cmd_mode = single(0);
            else
                mode = MODE_DOWN;
                v_cmd_mode = -v_button;
            end

        case MODE_STABILIZING
            % 静止待ちモード（上昇ボタン離し後）
            v_cmd_mode = single(0);  % 静止保持

            if btn_up || btn_down
                % ボタン押されたら中断してBALANCEへ
                mode = MODE_BALANCE;
            elseif abs(vel_wire) < v_stable_th
                % 静止中：カウンタ増加
                stable_cnt = stable_cnt_prev + uint16(1);

                if stable_cnt >= t_stable
                    % 静止確認完了 → 荷重更新してBALANCEへ
                    M_estimated = (I_motor * Kt * gear_ratio) / (g * drum_radius);
                    mode = MODE_BALANCE;
                    stable_cnt = uint16(0);
                else
                    mode = MODE_STABILIZING;
                end
            else
                % まだ動いている：カウンタリセット
                stable_cnt = uint16(0);
                mode = MODE_STABILIZING;
            end

        otherwise
            mode = MODE_BALANCE;
            v_cmd_mode = single(0);
    end
end
```

**荷重推定の動作フロー:**
```
1. 上昇ボタン押下 → UPモードで上昇
2. 上昇ボタン離す → STABILIZINGへ遷移
3. 速度が0.005m/s以下になるまで待機
4. 0.005m/s以下の状態が200ms継続
5. その時点のI_motorから M_estimated を計算
6. BALANCEモードへ遷移（外力追従有効）
```

#### Step 12: 重力補償ブロック

```
【Gravity Compensation サブシステム】

入力: M_estimated [kg]
出力: I_grav_comp [A]

計算式:
I_grav_comp = M_estimated * g * drum_radius / (Kt * gear_ratio)
            = M_estimated * 9.81 * 0.009 / (0.0404 * 15.04)
            = M_estimated * 0.1453

ブロック構成:
M_estimated → [Gain: g*drum_radius/(Kt*gear_ratio)] → I_grav_comp
              (Gain = 0.1453)
```

#### Step 13: 外力推定ブロック

```
【External Force Estimator サブシステム】

【重要】I_motor は フィルタ前の生電流 を使用すること！
        I_filtered（0.5Hz LPF後）を使うと外力検出ができなくなる

入力: I_motor [A] ※生電流, M_estimated [kg] ※Mode Controllerから
出力: F_ext [N]

計算式:
F_wire = I_motor * Kt * gear_ratio / drum_radius
       = I_motor * 0.0404 * 15.04 / 0.009
       = I_motor * 67.5

F_gravity = M_estimated * g
          = M_estimated * 9.81

F_ext = F_wire - F_gravity

ブロック構成:
I_motor（生電流）─[Gain: 67.5]────┐
                                   [Add: +-]──▶ F_ext
M_estimated ──────[Gain: 9.81]────┘

※M_estimated は上昇ボタン離し→静止時に更新された値（固定）
※I_motor はリアルタイムの電流値（外力の影響を含む）
```

#### Step 14: 仮想インピーダンス制御ブロック（BALANCEモード用）

```
【Virtual Impedance Controller サブシステム】

入力信号:
  - F_ext (single): 推定外力 [N]
  - v_prev (single): 前回の速度指令 [m/s] ← Unit Delayからのフィードバック

出力信号:
  - v_cmd (single): 速度指令 [m/s] → Unit Delayへも接続

パラメータ（関数内で定数定義）:
  - M_virtual: 仮想質量 [kg]
  - D_virtual: 仮想粘性 [N·s/m]
  - F_threshold: 不感帯閾値 [N]
  - v_max: 最大速度 [m/s]
  - dt: 制御周期 [sec]

計算式（離散化）:
if |F_ext| > F_threshold:
    F_eff = F_ext - sign(F_ext) * F_threshold
    v_cmd = v_prev + dt * (F_eff/M_virtual - D_virtual/M_virtual * v_prev)
else:
    v_cmd = v_prev * (1 - dt * D_virtual / M_virtual)  // 減衰

v_cmd = saturation(v_cmd, -v_max, +v_max)
```

**MATLAB Function ブロック使用:**

```matlab
function v_cmd = virtual_impedance(F_ext, v_prev)
%#codegen
% 仮想インピーダンス制御
%
% 入力:
%   F_ext  - 推定外力 [N]
%   v_prev - 前回の速度指令 [m/s] (Unit Delayからのフィードバック)
%
% 出力:
%   v_cmd  - 速度指令 [m/s]

    %% パラメータ（関数内で定義）
    M_v = single(1.0);       % 仮想質量 [kg]
    D_v = single(100.0);     % 仮想粘性 [N·s/m]
    F_th = single(19.6);     % 不感帯閾値 [N] (2kgf)
    v_max = single(0.03);    % 最大速度 [m/s]
    dt = single(0.001);      % 制御周期 [sec]

    %% 不感帯処理
    if abs(F_ext) > F_th
        % 有効外力（閾値超過分）
        if F_ext > 0
            F_eff = F_ext - F_th;
        else
            F_eff = F_ext + F_th;
        end

        % 仮想運動方程式の離散化
        % M_v * dv/dt + D_v * v = F_eff
        % v_new = v_old + dt * (F_eff/M_v - D_v/M_v * v_old)
        v_cmd = v_prev + dt * (F_eff / M_v - D_v / M_v * v_prev);
    else
        % 不感帯内：減衰のみ
        v_cmd = v_prev * (1 - dt * D_v / M_v);
    end

    %% 速度リミット
    if v_cmd > v_max
        v_cmd = v_max;
    elseif v_cmd < -v_max
        v_cmd = -v_max;
    end
end
```

```
           │             └────────────────────────────────┘   │
```

**MATLAB Function ブロック使用（推奨）:**

```matlab
function [I_cmd, I_integral] = velocity_pi_controller(v_cmd, vel_wire, I_grav_comp, I_integral_prev)
%#codegen
% 速度PI制御（重力補償フィードフォワード付き）
%
% 入力:
%   v_cmd          - 速度指令 [m/s]
%   vel_wire   - フィルタ後実速度 [m/s]
%   I_grav_comp    - 重力補償電流 [A]（フィードフォワード）
%   I_integral_prev - 前回の積分値 [A]（Unit Delayから）
%
% 出力:
%   I_cmd      - 電流指令 [A]
%   I_integral - 積分値 [A]（Unit Delayへ）

    %% パラメータ（関数内で定義）
    Kp_vel = single(10.0);   % 速度比例ゲイン [A/(m/s)]
    Ki_vel = single(50.0);   % 速度積分ゲイン [A/(m/s)/s]
    I_max = single(4.36);    % 電流上限 [A]
    I_min = single(-4.36);   % 電流下限 [A]
    dt = single(0.001);      % 制御周期 [sec]

    %% 速度誤差
    v_error = v_cmd - vel_wire;

    %% 比例項
    I_p = Kp_vel * v_error;

    %% 積分項（Forward Euler）
    I_i_raw = I_integral_prev + Ki_vel * v_error * dt;

    %% Anti-windup（積分値をリミット）
    if I_i_raw > I_max
        I_integral = I_max;
    elseif I_i_raw < I_min
        I_integral = I_min;
    else
        I_integral = I_i_raw;
    end

    %% 電流指令（P + I + 重力補償FF）
    I_cmd_raw = I_p + I_integral + I_grav_comp;

    %% 出力リミット
    if I_cmd_raw > I_max
        I_cmd = I_max;
    elseif I_cmd_raw < I_min
        I_cmd = I_min;
    else
        I_cmd = I_cmd_raw;
    end
end
```

**Unit Delay ブロックの設定:**

```
ライブラリ: Simulink → Discrete → Unit Delay

パラメータ:
  - Initial condition: 0
  - Sample time: dt (0.001)
  - Output data type: single
```

**接続手順:**

```
1. MATLAB Functionブロック配置（velocity_pi_controller）
2. Unit Delayブロック配置
3. 接続:
   - v_cmd（モード制御出力 or 仮想インピーダンス出力）→ MATLAB Function の v_cmd
   - vel_wire（Signal Processing出力）→ MATLAB Function の vel_wire
   - I_grav_comp（重力補償ブロック出力）→ MATLAB Function の I_grav_comp
   - MATLAB Function の I_integral → Unit Delay の入力
   - Unit Delay の出力 → MATLAB Function の I_integral_prev
   - MATLAB Function の I_cmd → 後段へ（モード切替 or 出力）
```

**パラメータ調整ガイド:**

| パラメータ | 初期値 | 調整方向 | 効果 |
|-----------|--------|----------|------|
| Kp_vel | 10.0 | 大きく | 応答が速くなるが振動しやすい |
| Kp_vel | 10.0 | 小さく | 安定だが追従が遅い |
| Ki_vel | 50.0 | 大きく | 定常偏差が小さくなるがオーバーシュート増 |
| Ki_vel | 50.0 | 小さく | 安定だが定常偏差が残る可能性 |

**注意事項:**
- モード切替時（BALANCE→UP/DOWN）に積分値をリセットする場合は、モード制御から積分リセット信号を追加
- 実機調整時はKp_velから調整し、振動が出ない範囲で大きくする
- 次にKi_velを調整し、定常偏差を小さくする

#### Step 16: 速度指令切替（Multiport Switch）

**重要: 仮想インピーダンス制御の出力は「速度指令」であり、速度PI制御の出力は「電流指令」です。
単位が異なるため、「速度指令」の段階で切り替え、共通の速度PI制御に入力します。**

```
【Velocity Command Selector（速度指令切替）】

機能: mode に応じて速度指令を切り替える

入力信号:
  - mode (uint8): 動作モード (1=BALANCE, 2=UP, 3=DOWN)
  - v_cmd_balance (single): 仮想インピーダンス制御出力 [m/s]
  - v_cmd_mode (single): モード制御出力 [m/s]（UP: +0.03, DOWN: -0.03）

出力信号:
  - v_cmd (single): 統合速度指令 [m/s] → 速度PI制御へ

切替ロジック:
  mode=1 (BALANCE) → v_cmd_balance（仮想インピーダンス出力）
  mode=2 (UP)      → v_cmd_mode（+0.03 m/s）
  mode=3 (DOWN)    → v_cmd_mode（-0.03 m/s）
```

**ブロック図:**

```
                         ┌─────────────────────────────┐
v_cmd_balance ──────────▶│ 1                           │
                         │                             │
v_cmd_mode ─────────────▶│ 2,3   Multiport Switch     │──▶ v_cmd
                         │                             │
mode ───────────────────▶│ ctrl                        │
                         └─────────────────────────────┘
```

**Multiport Switch ブロック設定:**

```
ライブラリ: Simulink → Signal Routing → Multiport Switch

パラメータ:
  - Data port order: One-based contiguous
  - Number of data ports: 3
  - Data port for default case: Last data port

接続:
  - ctrl (制御入力): mode
  - Data port 1: v_cmd_balance（BALANCE用）
  - Data port 2: v_cmd_mode（UP用）
  - Data port 3: v_cmd_mode（DOWN用）※UP/DOWNは同じ信号源だがmodeで符号が変わる
```

**注意:** v_cmd_modeはMode Controllerで既にUP時は+0.03、DOWN時は-0.03を出力しているため、
Data port 2と3は同じv_cmd_modeを接続すればOKです。

### 8.4 実機調整手順

#### Step 1: 重力補償調整
```
1. 既知の荷重（例：10kg）を吊り下げ
2. バランスモードで静止させる
3. 電流値を確認し、計算値と比較
4. 誤差があればKtまたはgear_efficiencyを微調整
```

#### Step 2: 仮想インピーダンス調整
```
1. M_virtual を調整
   - 小さくする → 軽く感じる（応答が速い）
   - 大きくする → 重く感じる（応答が遅い）

2. D_virtual を調整
   - 小さくする → 滑らかだが不安定になりやすい
   - 大きくする → 安定だが粘る感じになる

3. 推奨初期値: M_v=1.0, D_v=100
   「ふわふわ」感を出すには M_v=0.5〜1.0, D_v=50〜100 程度
```

#### Step 3: 速度制御ゲイン調整
```
1. Kp_vel を調整
   - 大きくする → 応答が速いが振動しやすい
   - 小さくする → 応答が遅いが安定

2. Ki_vel を調整
   - 大きくする → 定常偏差が小さいがオーバーシュート増
   - 小さくする → 定常偏差が残る可能性
```

## 付録C: 仮想インピーダンス制御のやさしい解説

### C.1 この付録について

この付録では、「仮想インピーダンス制御」を中学生でもわかるように説明します。
数式は最小限にして、身近な例えを使って解説します。

---

### C.2 サーボバランサーってなに？

まず、サーボバランサーが何をする機械なのか確認しましょう。

```
【サーボバランサーのイメージ】

        天井
    ━━━━━━━━━━━━
          ┃
       ┌──┴──┐
       │モーター│  ← コンピュータで制御
       └──┬──┘
          ┃ ワイヤ
          ┃
       ┌──┴──┐
       │ 荷物  │  ← 例えば20kgの箱
       │ 20kg │
       └─────┘
          ↓
        重力（下に引っ張る力）
```

**普通のクレーンとの違い：**
- 普通のクレーン → ボタンを押すと上がる、離すと止まる（カクカク）
- サーボバランサー → 荷物を手で押すと「ふわっ」と動く（なめらか）

**目標：** 20kgの重い荷物を、まるで風船のように軽く動かせるようにしたい！

---

### C.3 「インピーダンス」ってなに？

**インピーダンス = 動きにくさ** のことです。

身近な例で考えてみましょう：

```
【動きにくさの例】

例1: 空気中で手を振る → 簡単（インピーダンス小さい）
     ~~~~~~~~ スイスイ

例2: 水の中で手を振る → ちょっと重い（インピーダンス中くらい）
     ≋≋≋≋≋≋≋≋ ゆっくり

例3: ハチミツの中で手を振る → すごく重い！（インピーダンス大きい）
     ████████ ズズズ...
```

**インピーダンスが決まる2つの要素：**

| 要素 | 意味 | 例え |
|------|------|------|
| **質量（重さ）** | 動き始めの重さ | ボウリング玉 vs ピンポン玉 |
| **粘性（ねばり）** | 動いてる時の抵抗 | 水 vs ハチミツ |

---

### C.4 「仮想」ってなに？

**仮想 = コンピュータが「あるふり」をする** ことです。

```
【仮想の意味】

現実世界:              コンピュータの世界:
┌─────────┐           ┌─────────┐
│  荷物    │           │  荷物    │
│  20kg   │     →     │  1kg    │  ← 「1kgのふり」
│ (重い)   │   変換    │ (軽い)   │    をさせる！
└─────────┘           └─────────┘

実際は20kgだけど、
コンピュータが「1kgみたいに動け！」と
モーターに命令する
```

**つまり「仮想インピーダンス制御」とは：**

> コンピュータが「この荷物は実際より軽くて、
> 空気より少しだけ粘り気のある空間にあるふり」
> をさせる制御方法

---

### C.5 3つの調整つまみ

仮想インピーダンス制御には、3つの「調整つまみ」があります。

```
┌────────────────────────────────────────────┐
│        仮想インピーダンス調整パネル          │
├────────────────────────────────────────────┤
│                                            │
│   【仮想質量 M_v】      【仮想粘性 D_v】    │
│      ◎────────          ◎────────       │
│     軽い    重い        サラサラ  ネバネバ   │
│      1kg              100 N·s/m            │
│                                            │
│   【不感帯 F_th】                          │
│      ◎────────                            │
│     敏感     鈍い                          │
│      20N (約2kgの力)                       │
│                                            │
└────────────────────────────────────────────┘
```

#### つまみ①：仮想質量（M_v）= 1kg

**「どれくらい軽く感じさせるか」を決める**

```
M_v = 大きい(5kg)     M_v = 小さい(0.5kg)
     ↓                      ↓
  重く感じる              軽く感じる
  ゆっくり動く            素早く動く
  「よいしょ」            「ふわっ」
```

- M_v = 1kg にすると → 20kgの荷物が1kgに感じる！
- 小さくしすぎると → ちょっと触っただけで飛んでいく（危険）
- 大きくしすぎると → 重くて動かしにくい（意味ない）

#### つまみ②：仮想粘性（D_v）= 100

**「どれくらいブレーキをかけるか」を決める**

```
D_v = 小さい(10)       D_v = 大きい(500)
     ↓                      ↓
  ツルツル滑る            ネバネバ止まる
  止めにくい              止めやすい
  フラフラ不安定          ピタッと安定
```

- D_v = 100 くらいが「ちょうどいい粘り気」
- 小さすぎると → 押したら止まらない！グラグラ！
- 大きすぎると → 動きが遅くなる、操作が重い

#### つまみ③：不感帯（F_th）= 約20N（2kgの力）

**「どれくらいの力で動き始めるか」を決める**

```
不感帯のイメージ:

    力を加える
        ↓
    ┌───────────────────────┐
    │         不感帯          │
    │   この範囲では動かない   │
    │  ←───── 20N ─────→   │
    └───────────────────────┘
         ↓
    20Nを超えたら動き始める！
```

- F_th = 20N（約2kgの力）にすると
  - 1kgの力で押す → 動かない（ちょっと触っただけ）
  - 3kgの力で押す → 動く！（しっかり押した）

**なぜ不感帯が必要？**
- 振動やノイズで勝手に動くのを防ぐ
- 「しっかり押したときだけ動く」安全設計

---

### C.6 全部まとめると…

```
【仮想インピーダンス制御の動作】

ステップ1: 人が荷物を押す
           ↓
ステップ2: センサーが「どれくらいの力で押されたか」を測る
           ↓
ステップ3: 不感帯チェック
           - 20N以下 → 動かない（終了）
           - 20N超え → 次へ
           ↓
ステップ4: 「仮想質量1kg、仮想粘性100」で
           どれくらいの速度で動くべきか計算
           ↓
ステップ5: モーターに「この速度で動け！」と命令
           ↓
ステップ6: 荷物が「ふわっ」と動く！
```

---

### C.7 具体例で理解しよう

**例：20kgの箱を30N（約3kg）の力で押し下げた場合**

```
入力：押す力 = 30N（下向き）

ステップ1: 不感帯チェック
  30N > 20N（不感帯）→ OK、動く！

ステップ2: 有効な力を計算
  有効な力 = 30N - 20N = 10N
  （不感帯を超えた分だけが「本当の力」）

ステップ3: 速度を計算（簡単バージョン）
  仮想質量1kgの物体を10Nで押すと…
  加速度 = 力 ÷ 質量 = 10 ÷ 1 = 10 m/s²

  でも粘性(D_v=100)があるので、
  最終的には 3cm/s くらいの速度に落ち着く

ステップ4: モーターに命令
  「3cm/sで下降しろ！」

結果：20kgの箱が、まるで1kgの箱みたいに
     「すーっ」と下に動く！
```

## 付録D: ホールカウンタからのモーター速度算出

### D.1 なぜホールカウンタを使うのか

モータードライバが出力する速度信号は、ドライバ内部でフィルタ処理されているため、
**応答が遅い**場合があります。制御性能を上げるには、ホールセンサの信号から
直接速度を計算する方法が有効です。

```
【速度取得方法の比較】

方法1: ドライバ出力の速度信号を使用
┌──────────┐    ┌──────────────┐    ┌──────────┐
│ ホール   │───▶│  ドライバ内部 │───▶│ 速度出力  │
│ センサ  │    │  処理(遅い)   │    │ vel_motor │
└──────────┘    └──────────────┘    └──────────┘
                    ↑
              フィルタで遅延発生

方法2: ホールカウンタから直接計算 ★推奨★
┌──────────┐    ┌──────────────┐    ┌──────────┐
│ ホール   │───▶│  マイコンで   │───▶│ 速度計算  │
│ センサ  │    │  カウント     │    │ (高速)    │
└──────────┘    └──────────────┘    └──────────┘
                    ↑
              直接処理で高速応答
```

---

### D.2 ホールセンサの基礎知識

#### D.2.1 BLDCモーターのホールセンサ構成

maxon EC45 flat 651614 は **8極対（16極）** のモーターで、
**3つのホールセンサ（U, V, W）** が120°間隔で配置されています。

```
【ホールセンサ配置（8極対の場合）】

        N   S   N   S   N   S   N   S
     ┌───┬───┬───┬───┬───┬───┬───┬───┐
     │ 1 │ 2 │ 3 │ 4 │ 5 │ 6 │ 7 │ 8 │  ← 磁極（8極対=16極）
     └───┴───┴───┴───┴───┴───┴───┴───┘
           ↑       ↑       ↑
         Hall_U  Hall_V  Hall_W
         (120°間隔)

1回転で 8極対 × 6状態 = 48パルス（エッジ）
```

#### D.2.2 ホール信号パターン

3つのホールセンサの組み合わせで6つの状態が生成されます：

| 状態 | Hall_U | Hall_V | Hall_W | 電気角 |
|------|--------|--------|--------|--------|
| 1 | 1 | 0 | 1 | 0° |
| 2 | 1 | 0 | 0 | 60° |
| 3 | 1 | 1 | 0 | 120° |
| 4 | 0 | 1 | 0 | 180° |
| 5 | 0 | 1 | 1 | 240° |
| 6 | 0 | 0 | 1 | 300° |

**1機械回転あたりのホールエッジ数：**
```
エッジ数 = 極対数 × 6 = 8 × 6 = 48 エッジ/回転
```

### D.3 速度計算方法

#### D.3.1 方法A: パルスカウント法（位置差分法）

一定時間（制御周期dt）内のカウント変化量から速度を計算します。

```
【計算式】
                   Δcount × 2π
ω_motor [rad/s] = ─────────────────
                   edges_per_rev × dt

Δcount: 制御周期内のカウント変化量
edges_per_rev: 1回転あたりのエッジ数 = 48
dt: 制御周期 [sec] = 0.001
```

**具体例（3cm/s上昇時）：**
```
ワイヤ速度 v = 0.03 m/s
モーター角速度 ω = v × gear_ratio / drum_radius
                = 0.03 × 15.04 / 0.009
                = 50.1 rad/s
                = 478 rpm

1秒あたりのエッジ数 = 478/60 × 48 = 382 エッジ/秒
1ms（制御周期）あたり = 0.38 エッジ

※低速では1制御周期に1エッジも来ないことがある！
```

#### D.3.2 方法B: 周期計測法（パルス間隔法）

連続するエッジ間の時間を計測して速度を計算します。

```
【計算式】
                      2π
ω_motor [rad/s] = ─────────────────────
                   edges_per_rev × T_edge

T_edge: エッジ間の時間 [sec]
```

**メリット・デメリット：**

| 方法 | メリット | デメリット |
|------|----------|------------|
| A: パルスカウント法 | 実装が簡単、高速時に正確 | 低速時に分解能不足 |
| B: 周期計測法 | 低速時も正確 | 高速時に処理が重い、タイマー必要 |

**推奨：方法Aを基本とし、LPFで平滑化**

```matlab
function vel_motor = hall_velocity_calc(hall_cnt, hall_cnt_prev, vel_prev)
%#codegen
% ホールカウンタからモーター速度を計算
%
% 入力:
%   hall_cnt      - 現在のホールカウンタ値 (int32)
%   hall_cnt_prev - 前回のホールカウンタ値 (int32)
%   vel_prev      - 前回の速度出力 [rad/s] (single)
%
% 出力:
%   vel_motor     - モーター角速度 [rad/s] (single)

    %% パラメータ
    edges_per_rev = int32(48);    % 1回転あたりのエッジ数（8極対×6）
    dt = single(0.001);           % 制御周期 [sec]

    % LPFパラメータ（10Hz）
    fc = single(10.0);
    alpha = single(2*pi*fc*dt / (2*pi*fc*dt + 1));  % ≈ 0.059

    %% カウンタ差分計算
    % オーバーフロー対策（32bit符号付き）
    diff_cnt = hall_cnt - hall_cnt_prev;

    %% 速度計算 [rad/s]
    % ω = Δcount × 2π / (edges_per_rev × dt)
    vel_raw = single(diff_cnt) * single(2*pi) / (single(edges_per_rev) * dt);

    %% LPFによる平滑化
    vel_motor = alpha * vel_raw + (1 - alpha) * vel_prev;

end
```

### D.6 注意事項

#### D.6.1 低速時の分解能問題

```
【問題】
3cm/s運転時: 約0.38エッジ/ms
→ 2-3制御周期に1エッジしか来ない
→ 速度が0と有限値の間でガタガタする

【対策】
1. LPFのカットオフ周波数を下げる（5Hz程度）
2. 複数周期分のカウントを使う（移動平均）
3. 周期計測法と併用（低速時のみ切り替え）
```

#### D.6.2 カウンタオーバーフロー対策

```matlab
% 32bit符号付き整数の差分計算は自動的にオーバーフロー対応
% ただし、1制御周期で2^31以上変化しないことが前提

% 最大速度での確認:
% 仮に1000rad/s（≈9550rpm、非現実的な高速）の場合
% Δcount = 1000 × 48 / (2π) × 0.001 = 7.6 count/ms
% → 十分小さいのでオーバーフローの心配なし
```

#### D.6.3 ノイズ対策

```
【ホール信号のノイズ源】
- 電気的ノイズ（スイッチングノイズ等）
- 振動による誤カウント
- チャタリング

【対策】
1. ハードウェア: シュミットトリガ入力、プルアップ/プルダウン抵抗
2. ソフトウェア: デジタルフィルタ（LPF）
3. 異常検出: 急激な速度変化を検出してリジェクト
```

#### E.3.1 maxon EC45 flat 651614 のパラメータ

Motor Control BlocksetのPMSMブロックに設定するパラメータ：

| パラメータ | 記号 | 値 | 単位 | 備考 |
|-----------|------|-----|------|------|
| 相抵抗 | Rs | 0.287 | Ω | 端子間0.573Ωの半分 |
| d軸インダクタンス | Ld | 0.151 | mH | 端子間0.301mHの半分 |
| q軸インダクタンス | Lq | 0.151 | mH | 表面磁石型なのでLd=Lq |
| 永久磁石鎖交磁束 | λpm | 0.00337 | Wb | Kt/(1.5×p)から計算 |
| 極対数 | p | 8 | - | 16極 |
| ローターイナーシャ | J | 1.81×10⁻⁵ | kg·m² | |
| 粘性摩擦係数 | B | 1×10⁻⁶ | Nm·s/rad | 推定値 |

#### E.3.2 パラメータの計算根拠

```
【相抵抗】
データシート: 端子間抵抗 R_LL = 0.573 Ω
Y結線の場合: Rs = R_LL / 2 = 0.287 Ω

【インダクタンス】
データシート: 端子間インダクタンス L_LL = 0.301 mH
Y結線の場合: Ls = L_LL / 2 = 0.151 mH
表面磁石型(SPM): Ld = Lq = Ls

【永久磁石鎖交磁束】
トルク式: T = (3/2) × p × λpm × Iq
トルク定数: Kt = T/I = (3/2) × p × λpm
よって: λpm = Kt / (1.5 × p) = 0.0404 / (1.5 × 8) = 0.00337 Wb

【電気時定数】
τe = Ls / Rs = 0.151e-3 / 0.287 = 0.53 ms
```

```matlab
function T_load = calc_load_torque(M_load, F_external, omega_drum)
%#codegen
% 負荷トルク計算（モーター軸換算）
%
% 入力:
%   M_load     - 荷物質量 [kg]
%   F_external - 外力 [N]（+:上向き、荷物を持ち上げる方向）
%   omega_drum - ドラム角速度 [rad/s]
%
% 出力:
%   T_load     - モーター軸負荷トルク [Nm]

    %% パラメータ
    g = single(9.81);
    drum_radius = single(0.009);
    gear_ratio = single(15.04);
    gear_efficiency = single(0.9);

    %% 重力による負荷トルク（モーター軸換算）
    F_gravity = M_load * g;              % 重力 [N]
    T_gravity = F_gravity * drum_radius; % ドラム軸トルク [Nm]
    T_gravity_motor = T_gravity / (gear_ratio * gear_efficiency);  % モーター軸 [Nm]

    %% 外力による負荷トルク
    % 外力が上向き(+)の場合、負荷が軽くなる → 負荷トルク減少
    T_ext = -F_external * drum_radius / (gear_ratio * gear_efficiency);

    %% 合計負荷トルク
    T_load = T_gravity_motor + T_ext;
end
```

### E.6 簡易モーターモデル（Motor Control Blockset不要版）

Motor Control Blocksetのブロックを使わずに、同等の動作をMATLAB Functionで実現する方法：

```matlab
function [I_motor, omega_motor, theta_motor] = simple_pmsm_model(...
    V_abc, T_load, omega_prev, theta_prev, I_dq_prev)
%#codegen
% 簡易PMSMモデル（dq座標系）
%
% 入力:
%   V_abc      - 3相電圧指令 [V] (3x1)
%   T_load     - 負荷トルク [Nm]
%   omega_prev - 前回角速度 [rad/s]
%   theta_prev - 前回電気角 [rad]
%   I_dq_prev  - 前回dq電流 [A] (2x1)
%
% 出力:
%   I_motor    - 相電流実効値 [A]
%   omega_motor - 角速度 [rad/s]
%   theta_motor - 電気角 [rad]

    %% パラメータ
    Rs = single(0.287);
    Ld = single(0.151e-3);
    Lq = single(0.151e-3);
    lambda_pm = single(0.00337);
    p = single(8);
    J = single(1.81e-5);
    B = single(1e-6);
    dt = single(1e-5);  % 計算周期 10μs

    %% Clarke変換（abc → αβ）
    V_alpha = (2/3) * (V_abc(1) - 0.5*V_abc(2) - 0.5*V_abc(3));
    V_beta  = (2/3) * (sqrt(3)/2*V_abc(2) - sqrt(3)/2*V_abc(3));

    %% Park変換（αβ → dq）
    cos_theta = cos(theta_prev);
    sin_theta = sin(theta_prev);
    V_d = V_alpha * cos_theta + V_beta * sin_theta;
    V_q = -V_alpha * sin_theta + V_beta * cos_theta;

    %% 電気系方程式（オイラー法）
    % dId/dt = (Vd - Rs*Id + omega_e*Lq*Iq) / Ld
    % dIq/dt = (Vq - Rs*Iq - omega_e*Ld*Id - omega_e*lambda_pm) / Lq
    omega_e = p * omega_prev;  % 電気角速度

    dId_dt = (V_d - Rs*I_dq_prev(1) + omega_e*Lq*I_dq_prev(2)) / Ld;
    dIq_dt = (V_q - Rs*I_dq_prev(2) - omega_e*Ld*I_dq_prev(1) - omega_e*lambda_pm) / Lq;

    I_d = I_dq_prev(1) + dId_dt * dt;
    I_q = I_dq_prev(2) + dIq_dt * dt;

    %% トルク計算
    T_motor = 1.5 * p * lambda_pm * I_q;

    %% 機械系方程式
    domega_dt = (T_motor - T_load - B*omega_prev) / J;
    omega_motor = omega_prev + domega_dt * dt;

    %% 電気角更新
    theta_motor = theta_prev + omega_e * dt;
    theta_motor = mod(theta_motor, 2*pi);

    %% 出力
    I_motor = sqrt(I_d^2 + I_q^2);  % 相電流実効値
end
```
