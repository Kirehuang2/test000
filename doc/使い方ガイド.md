# 使い方ガイド

## 1. 開発環境セットアップ

### 必要なもの
- e2 studio (Renesas IDE)
- E2 Lite デバッガ
- MATLAB (BLE Monitor用)
- Makita 18Vバッテリー (BL1820B等)
- maxon EC flat 651614 モーター
- 自作モータードライバ基板 (RA6T2 + DRV8302)

### ビルドと書き込み
1. e2 studio でプロジェクト `000` を開く
2. Debug構成でビルド
3. E2 Lite 経由で書き込み
4. デバッグ実行開始

---

## 2. BLE Monitor (MATLAB)

### 起動
```matlab
cd matlab
ble_monitor
```

### 接続
1. 起動時にBLEデバイスのスキャンダイアログが表示
2. DA14531MOD を選択して接続
3. 「Notifications subscribed」と表示されれば接続完了

### 画面構成
- 上部: BLEコマンド送信欄
- 中央: リアルタイムグラフ (5チャンネル選択可能)
- 下部: ログ表示

### プロットチャンネル

| 1 | (none) | - |
| 2 | RPM | RPM |

## 3. BLEコマンド一覧

### モーター制御

| コマンド | 説明 | 例 |
|----------|------|-----|
| `E1` | モーター有効化 (EN_GATE ON + PWM ON) | `E1` |
| `E0` | モーター無効化 (PWM OFF + EN_GATE OFF、モーター解放) | `E0` |
| `C0` | 速度制御モード | `C0` |
| `C1` | トルク制御モード | `C1` |

### トルク制御

| コマンド | 説明 | 例 |
|----------|------|-----|
| `T{n}` | トルク指令 (n/1000 PU) | `T30` = 0.03PU, `T-30` = -0.03PU(逆転) |
| `L{n}` | トルク上限 (n/1000 PU) | `L60` = 0.06PU上限, `L200` = 0.20PU |

### 速度制御

| コマンド | 説明 | 例 |
|----------|------|-----|
| `M{n}` | 速度指令 [RPM] (±4400まで) | `M500` = 500RPM, `M2000` = 2000RPM |

### パラメータ設定

| コマンド | 説明 | 例 |
|----------|------|-----|
| `SET {name} {val}` | パラメータ設定 | `SET Ki_iq 1.0` |
| `GET {name}` | パラメータ取得 | `GET Ki_iq` |
| `D` | 全変数ダンプ (V0~V57) | `D` |
| `LIST` | 変数名一覧 | `LIST` |

### ログ

| コマンド | 説明 | 例 |
|----------|------|-----|
| `LOG START {hz}` | ログ開始 (デフォルト100Hz) | `LOG START 100` |
| `S` | ログ停止 | `S` |

ログ停止後、CSVファイル保存ダイアログが表示される。

### キャリブレーション

| コマンド | 説明 |
|----------|------|
| `SET cal_sweep 1` | Hallオフセット自動キャリブレーション開始 (約30秒) |

## 4. 基本操作手順

### トルク制御テスト

```
C1              ← トルク制御モード
L60             ← 上限 0.06PU (1.0A)
T30             ← トルク指令 0.03PU (0.5A)
E1              ← モーター起動
LOG START 100   ← ログ開始 (100Hz)
                   ... テスト中 ...
S               ← ログ停止 (CSV保存ダイアログ)
E0              ← モーター停止
```

### 逆転テスト

```
T-30            ← 逆転トルク -0.03PU
E1              ← モーター起動 (FSPリセット後に起動)
```

### 速度制御テスト

```
C0              ← 速度制御モード
SET Kp_speed 0.78
SET Ki_speed 1.5
SET integrator_limit 0.5
M500            ← 速度指令 500RPM
E1              ← モーター起動
LOG START 100
                   ... M1000, M2000 と段階的に上げる ...
S               ← ログ停止
E0              ← モーター停止
```

### トルクを上げるとき

```
L200            ← 上限を先に上げる
T100            ← トルク指令を上げる
T150
T200            ← 0.20PU = 3.3A (定格)
```

| 値 | 意味 |

## 7. トラブルシューティング

### モーターが起動しない
1. `D` でV37(oc_fault)確認 → 1なら `E0` でクリアしてから `E1`
2. V2(battery_voltage) > 14V か確認
3. V5(protection_state) = 0 か確認

### E1で電源が落ちる
- EN_GATE/PWM初期化の問題。リビルドして再書き込み

### ログがタイムアウトする
- BLE接続が切れている → 再接続
- デバッグ実行を忘れている → e2 studioでデバッグ開始

### モーターが振動する
- `D` でV25(Ki_id)が0か確認 → 0以外ならドリフトの原因
- `SET Ki_id 0` で解消

### E0後もモーターが重い
- デバッグ実行中はEN_GATEが有効 → 正常動作ではE0でモーター解放

### 逆転できない
- FSPリセットが必要 → E0してからE1で自動リセット
- hall_offset確認 → `SET hall_offset 0.01`

### 速度制御で目標RPMに届かない
- `SET integrator_limit 0.5` で改善する場合あり (高速域の電圧飽和対策)
- `SET Kp_speed 0.78` / `SET Ki_speed 1.5` を確認 (N_base=4750用の推奨値)
- IqRefがSimulink飽和(0.194)に張り付いている場合、電圧マージン不足
