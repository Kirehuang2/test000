# 微分なしDOB（外乱オブザーバー）の式の導出

## 概要

外乱オブザーバー（DOB）は「邪魔する力」を推定する仕組みだが、通常の実装では速度の微分（加速度）が必要でノイズに弱い。式を変形することで、微分を使わずに同じ結果を得られる。

---

## 出発点

### モーターの運動方程式

```
J × 加速度 = 命令した力 − 邪魔する力

→ 邪魔する力 = 命令した力 − J × 加速度
```

加速度（`dω/dt`）はノイズまみれなので、Qフィルタ（ローパスフィルタ）を通す：

```
d̂ = Qフィルタ ( 命令した力 − J × 加速度 )    ← ふつうのDOBの式
```

### 記号の定義

| 記号 | 意味 |
|------|------|
| `d̂` | 推定した外乱（邪魔する力） |
| `τ_cmd` | 命令した力（トルク指令） |
| `ω` | 速度（角速度） |
| `J` | 慣性モーメント（重さに相当） |
| `ωq` | Qフィルタのカットオフ周波数（反応速度のつまみ） |
| `s` | ラプラス演算子（`s·X` = `X`の微分） |
| `Q(s)` | Qフィルタ = `ωq / (s + ωq)` |

---

## Step 1：Qフィルタを式で書く

Q(s) = `ωq / (s + ωq)` なので：

```
d̂ = ωq/(s+ωq) × ( τ_cmd − J·s·ω )
```

両辺に `(s + ωq)` をかけて分母を消す：

```
(s + ωq) × d̂ = ωq × ( τ_cmd − J·s·ω )
```

左辺を展開：

```
s·d̂ + ωq·d̂ = ωq·τ_cmd − ωq·J·s·ω
```

`s·d̂` を左辺に残す：

```
s·d̂ = −ωq·d̂ + ωq·τ_cmd − ωq·J·s·ω
```

`s·何か` は「何かの微分」なので、時間の式に直すと：

```
dd̂/dt = −ωq·d̂ + ωq·τ_cmd − ωq·J·(dω/dt)
                                     ↑
                               まだ微分（加速度）が残っている！
```

**これが出発点。ここから微分を消す。**

---

## Step 2：秘密の箱 p を定義する

以下のように **狙って** 定義する：

```
p = d̂ + J·ωq·ω
```

### なぜこの形？

元の式に `−ωq·J·(dω/dt)` という邪魔な項がある。これを打ち消すために `+J·ωq·(dω/dt)` が必要。

「`J·ωq·ω` を微分すれば `J·ωq·(dω/dt)` が出てくる」

→ だから `p = d̂ + J·ωq·ω` と定義すれば、`dp/dt` の中に `+J·ωq·(dω/dt)` が自然に現れて打ち消せる。

**「消したい項をわざと足しておいて、微分したときに打ち消す」という逆算の発想。**

### p を微分する

```
dp/dt = dd̂/dt + J·ωq·(dω/dt)
```

---

## Step 3：代入して打ち消す

Step 1 の結果（`dd̂/dt`）を代入する：

```
dp/dt = [ −ωq·d̂ + ωq·τ_cmd − ωq·J·(dω/dt) ]  +  J·ωq·(dω/dt)
         ~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~        ~~~~~~~~~~~~~~
                   Step1の dd̂/dt                   pの定義から出た項
```

`dω/dt` の項だけ抜き出すと：

```
−ωq·J·(dω/dt)  +  J·ωq·(dω/dt)  =  0
```

**完全に消えた！** 残るのは：

```
dp/dt = −ωq·d̂ + ωq·τ_cmd
```

---

## Step 4：d̂ も p と ω で書き換える

`p = d̂ + J·ωq·ω` を裏返すと：

```
d̂ = p − J·ωq·ω
```

これを代入：

```
dp/dt = −ωq·(p − J·ωq·ω) + ωq·τ_cmd

      = −ωq·p + J·ωq²·ω + ωq·τ_cmd
```

---

## 完成した式

```
┌────────────────────────────────────────────────┐
│                                                │
│  dp/dt = −ωq·p + Jn·ωq²·ω + ωq·τ_cmd        │
│                                                │
│  d̂ = p − Jn·ωq·ω                             │
│                                                │
│  → 微分(dω/dt)がどこにもない！                   │
│  → p, ω, τ_cmd の足し算・かけ算だけ             │
│                                                │
└────────────────────────────────────────────────┘
```

---

## 離散化（実装用）

連続系の式をサンプリング周期 `dt` で離散化する（前進オイラー法）：

```
p[k+1] = p[k] + dt × ( −ωq·p[k] + Jn·ωq²·ω[k] + ωq·τ_cmd[k] )

d̂[k]  = p[k] − Jn·ωq·ω[k]
```

### C言語実装

```c
#define WQ    3.0f       // カットオフ [rad/s]
#define J_N   1.81e-5f   // 名目慣性モーメント [kgm²]
#define DT    0.001f     // サンプリング周期 [s]

static float p = 0.0f;

float DOB_step(float tau_cmd, float omega) {
    // 式1: pを更新（積分のみ、微分なし）
    float p_dot = -WQ * p
                + J_N * WQ * WQ * omega
                + WQ * tau_cmd;
    p += p_dot * DT;

    // 式2: 外乱推定値を出力
    float d_hat = p - J_N * WQ * omega;

    return d_hat;
}
```

## ωq のチューニング

| ωq | 追従性 | ノイズ耐性 | 用途 |
|----|--------|-----------|------|
| 小（1 rad/s） | 遅い | 強い | ゆっくり変化する外力 |
| 中（3 rad/s） | 普通 | 普通 | 一般的な開始値 |
| 大（10 rad/s） | 速い | 弱い | 速い外力変化 |

**目安：速度制御帯域の 1/3 以下から始める。**

---

## 導出のポイントまとめ

1. ふつうのDOBは `dω/dt`（微分）が必要 → ノイズに弱い
2. `p = d̂ + J·ωq·ω` という変数を定義する
3. `dp/dt` を計算すると `dω/dt` の項が打ち消される
4. 結果、積分（足し算の累積）だけで外乱を推定できる
5. 数学的にふつうのDOBと完全に等価（答えは同じ）
